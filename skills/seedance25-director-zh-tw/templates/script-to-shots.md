# 模板：劇本 → 鏡頭 → 生成單元

## 第 1 步：一場戲

```
場 03　診所門口　清晨冷霧 → 轉暖　在場：Edna、Cole、Bo（狗）
作用：Edna 用一句話讓 Cole 放下恐懼（兌現：Cole 抬眼）
動作：Edna 從門廊走到皮卡旁，站到 Cole 身邊。
對白：Edna（溫暖略沙啞的老年女聲）："Don't let fear be what he sees. Let him see his partner."
反應：Cole 抬眼看她，吸一口氣，低頭看 Bo。
```

## 第 2 步：拆鏡頭

| 鏡頭 | 景別 / 機位 | 內容 | 開場接 |
|---|---|---|---|
| 3A | 中景 / 車右側 | Edna 入畫，站定 | 上一場結尾 Cole 在尾門 |
| 3B | 中近景 / 同側 | Edna 說臺詞 | 3A 結尾 |
| 3C | 中景 / 同側 | Cole 反應 | 3B 結尾 |

## 第 3 步：合併成生成單元

同一時空、同一組人、動作簡單 → 3A+3B+3C 合成 **U03（10 秒一鏡到底）**：

| 秒段 | 內容 |
|---|---|
| 0-2s | 開場同上一鏡構圖；Edna 從門廊一側入畫，停在 Cole 身邊 |
| 2-7s | Edna 看著 Cole 說臺詞；只有 Edna 說話 |
| 7-10s | Cole 抬眼，一口氣，低頭看 Bo；不留長對視 |

## 第 4 步：寫提示詞

套 `shot-prompt-domestic.md` 或 `canvas-prompt-overseas.md`。

## 第 5 步：自檢

- 每秒段只有一件主要的事？
- 開場與上一鏡結尾對得上？
- 有沒有刻意象徵動作？
- 兌現點在第幾秒？集尾有沒有問題留下？
