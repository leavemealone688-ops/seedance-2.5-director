# 出片 QC 清單

## 先做兩件事

```bash
scripts/contact_sheet.sh S03_v1.mp4 S03_v1_contact.png 2 5   # 每秒 2 幀聯絡表
scripts/contact_sheet.sh S03_v1.mp4 S03_v1_hands.png 6 6     # 每秒約 6 幀，專查手指和穿模
```
然後**完整聽一遍聲音**（對白、口型、有沒有配樂）。

## 清單

**角色**
- [ ] 臉與定妝照一致（每個角色單獨看，尤其入畫那一秒）
- [ ] 髮型輪廓、髮色、服裝、配飾、硬記號一致；沒有多出禁止飾品
- [ ] 服裝狀態對（赤腳 / 淋溼 / 脫外套）
- [ ] 人數對；沒有多出路人

**身體**
- [ ] 手指五根，沒有融合
- [ ] 沒有人和桌椅 / 車 / 動物穿模；配件（揹帶、鏈子）沒粘在物體上
- [ ] 動作方向對

**空間與連續性**
- [ ] 開場和上一鏡銜接幀一致：機位側、景別、站位、光色
- [ ] 人物左右沒互換，銀幕方向一致
- [ ] 道具位置、數量、狀態對
- [ ] 背景沒新增門、燈、裝置；文字沒亂碼（或可接受）
- [ ] 背景人物在動

**聲音**
- [ ] 臺詞完整、逐字正確、說話人正確
- [ ] 口型對得上；不說話的人沒動嘴（查末幀）
- [ ] 沒有怪聲（喘氣、尖叫）
- [ ] 有沒有模型自帶音樂（有 → 後期靜音）

**節奏與表演**
- [ ] 沒有刻意象徵動作、沒有對著鏡頭凝視
- [ ] 結尾空看多長 → 記下剪輯出點
- [ ] 鏡頭有沒有停在無意義的構圖上（例如長時間只拍下半身）

**技術**
- [ ] 時長、畫幅、解析度對（`ffprobe`）
- [ ] 硬切是否出現在不該切的地方
- [ ] 細紋理（岩石、水面、樹葉、布料、頭髮等）清晰，沒有塊狀 / 網格狀壓縮偽影

## 結論格式

`留用 / 留用需剪（出點 x.x s，靜音配樂）/ 重跑（原因 + 改哪句）`，記進分鏡表的鏡頭記錄。模板：`../templates/qc-report.md`。
