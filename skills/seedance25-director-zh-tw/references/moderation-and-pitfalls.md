# 審核與常見坑

## 審核規避寫法

| 型別 | 寫法建議 |
|---|---|
| 血、傷口、醫療操作 | `no blood, no medical procedure`；傷口用"乾淨的繃帶"；不拍手術過程 |
| 武器 | 能不出現就寫"不出現武器"；必須出現時只給剪影或一道光 |
| 火、爆炸 | 用光色暗示；"不出現明火"；奇幻火光寫成"暗紅暗橙的光"而非燃燒的人 |
| 打鬥 | 不寫毆打、踩人特寫；改成"手按手腕"等剋制動作；"兩者之間始終留出空當，沒有任何身體接觸"；腳和靴子不入畫 |
| 敏感詞 | 中文避免：血 / 屍體 / 殺 / 槍 / 死；用"倒下""不動了""紅色液體也不要" |
| 真人、品牌、logo | 不寫真人名字；車、衣服、招牌寫"no logos, no lettering" |
| 未成年人 | 避免任何敏感情境 |
| 歷史 / 政治 | 架空處理，不影射現實政治 |
| 暴露 | 服裝寫清楚完整 |
| 真人臉參考（海外畫布） | Vigloo 拒收含寫實人臉的上傳圖 → 走 Character 節點 + 空場首幀 |

安全句：
- `No weapons, no blood, no fire, no medical procedure. No text on screen.`
- `不出現武器、血跡、明火。畫面中不要任何文字、字幕、水印。`

## 被拒後的順序

1. 小云雀"视频可能不合规"：**原樣重試**（團隊經驗：會退積分，常能透過）。
2. 仍被拒：找最可能的敏感詞換成剋制寫法，記錄改了哪裡，先告訴負責人。
3. 參考圖本身也可能觸發（傷口、武器道具圖），必要時換圖。

## 生成品質的坑（團隊實測）

| 坑 | 原因 / 現象 | 對策 |
|---|---|---|
| 跑臉 | 用了生成截幀當臉部參考 | 只用原始定妝照 |
| 人和桌子 / 椅子穿模 | 多人入座、軀幹與桌沿融合 | 寫"solid, physically correct contact"；首幀先查；人少一點 |
| 手指數量不對 | 手部動作複雜、特寫 | 寫"natural hands with five fingers"；手部動作放中景、做簡單握拳/握腕；按約 6fps 抽幀數手指 |
| 網格 / 塊狀偽影 | 碎石、草葉、地毯等細紋理 | 按場景點名畫面裡實際有的細紋理並要求"細節清晰銳利，沒有塊狀或網格狀壓縮偽影"（見 `universal-rules.md` 第 9 節）；降低細紋理佔畫面比例；景別稍近；輕微的可接受，否則重跑 |
| 背景人物定住 | 沒寫背景動作 | 寫自然小動作，"they stay in place" |
| 背景亂碼招牌 | 模型自造文字 | 寫"plain, blank, no lettering"；用運鏡避開 |
| 道具瞬移 / 數量變化 | 長條裡尤甚 | 每拍重申位置和"只有這一隻" |
| 追逐動作被省略 | 長條裡動作太多 | 拆短拍，每拍一個動作 |
| 走反方向 | 方向描述模糊 | 寫死方向並加否定 |
| 多出的切鏡 | 寫了 SHOT/CUT 標籤或時間段太滿 | 刪標籤、減內容 |
| 不該說話的人張嘴 | 沒寫閉嘴 | `mouth stays closed, no lip movement`；QC 查末幀 |
| 自帶鋼琴 / 配樂 | 模型習慣 | 禁音樂寫兩遍 + 後期靜音 |
| 結尾空看 | 時間線末段太空 | 末段只給 1 秒，後期裁 |
| 刻意象徵動作 | 提示詞寫了儀式性動作 | 刪掉，見 `acting-and-pacing.md` |
| 某角色不露臉的要求被破壞 | 每段都要重申 | 每段重寫"背對鏡頭 / 臉在畫框外" |

## 操作紀律

- 同一條只點一次生成；不要重新整理畫布或雙擊（TapNow / Vigloo 會重複扣費）。
- **已提交的付費任務不要中途取消**。
- 一次只跑一條，確認透過再跑下一條；不要併發重複提交。
- 每次提交前把"平台、引數、參考順序、預計花費"列給負責人，得到同意再提交。
