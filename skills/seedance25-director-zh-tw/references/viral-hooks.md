# 爆款結構：鉤子、留存、反轉、結尾與資料迭代

> 本節的秒數和比例是豎屏短劇行業的常見經驗，不是平台公佈的標準。用你自己的後臺資料校準（見第 7 節）。

## 1. 一句話定位先於一切

寫劇本前先寫一句：`題材標籤 × 核心擰點`。擰點是**本劇真正的期待句**，不是"打臉逆襲"這種陳詞：
- "每晚十二點準時來電的號碼，是她十年前登出的手機"
- "全村只有她看得見那口井，而井裡的人在叫她的名字"

標題、封面、第一句臺詞都要從這句裡長出來。

## 2. 前 1-3 秒鉤子

第一幀就要有事。可用的鉤子型別：

| 型別 | 例子 | 提示詞怎麼寫 |
|---|---|---|
| 衝突已發生 | 一巴掌剛落下、離婚協議已按印 | `0-1s: open mid-action, …` 不寫起勢 |
| 視覺奇觀 | 地面裂成深淵、一屋子人同時回頭 | 第 0 秒就是奇觀的最大畫面 |
| 反常識臺詞 | "婚禮取消了，新郎是我爸" | 臺詞放在 0-2s，第一個字就開口 |
| 危險倒計時 | 手指離印泥只差毫釐 | 特寫 + 極慢推 |
| 身份落差 | 外賣員被當眾叫成"董事長" | 先給落差畫面再給反應 |
| 懸念物件 | 一張空白的降書、一隻不響的鈴 | 道具特寫開場 |

忌：空鏡開場、慢慢走進來、天空建立鏡頭、片頭字卡。

## 3. 前 30 秒必須落地的事

- 一個**不可逆事實**：按了手印、禁忌已觸發、死局已成。
- 一個**資訊差**：觀眾知道而戲裡人不知道（或反過來），這是追看的燃料。
- 主角的**目標**清楚，阻力露出第一層。

## 4. 留存節奏

- 每 10-20 秒給一個**小兌現或小反轉**（新資訊、局勢變化、一句狠話），不要連續 20 秒以上純鋪墊。
- 疏密對比：衝突段短鏡快切，情緒落點給 1-2 秒呼吸。
- 每場戲只推進一件事；同一資訊不重複交代。
- 對白短：一句一個資訊，能用動作交代的不說。
- 生成層面：一條 10-20 秒的提示詞對應一個"小兌現單元"，節拍表裡標出每個兌現點在第幾秒。

## 5. 反轉與兌現

- **埋設 → 兌現**：前面出現的道具 / 臺詞 / 能力，後面必須用上（例：開場一隻不響的鈴 → 集尾它自己響了一聲報警）。
- 反轉要有前置線索，回看能對上；沒有線索的反轉觀眾會覺得被騙。
- 可計量的爽點：按題材選計量方式（戰力對比、知情人數、倒計時、具體體貼的次數），每集至少兌現一次。
- 反轉鏡頭的拍法：先給反應，再給原因；或者先給原因的一半，讓觀眾先猜。

## 6. 結尾鉤子與 CTA

集尾鉤子型別：
- 威脅未解（門外的人還在拍門）
- 身份將揭（她抬頭看向那盞燈）
- 誤會加碼
- 資源將得 / 將失
- 糖後必險（溫情之後一個不安的細節）

規則：
- 集尾追看主問要和開場定位同根，不要中途換成無關問題。
- 結尾停在**問題剛被提出**的那一幀，不要停在答案後的空看。
- CTA（關注、看下集）放在成片外的文案或片尾 1 秒字卡，不要讓角色對鏡頭說"記得關注"，會破壞代入感。
- 提示詞層面：最後一段寫到"問題出現"的動作為止，結尾 0.5 秒可寫"畫面靜止"給剪輯留出點。

## 7. 豎屏短劇單集結構（參考）

| 段落 | 時長佔比（經驗） | 內容 |
|---|---|---|
| 鉤子 | 前 3 秒 | 衝突 / 奇觀 / 反常識臺詞 |
| 建立 | 到 15-20 秒 | 不可逆事實 + 資訊差 + 目標 |
| 推進 | 中段 | 2-3 個小兌現 / 小反轉 |
| 高點 | 後 1/4 | 本集最大的兌現或反轉 |
| 集尾鉤 | 最後 3-5 秒 | 新問題 |

拆到生成單元：每 10-20 秒一個單元，每單元一個節拍表（見 `../templates/script-to-shots.md`）。

## 8. 封面與標題

- 封面：9:16，用最強衝突幀或重做高畫質版；大字 3-8 個字，寫衝突或懸念；人物臉大、表情清楚；字避開平台 UI。
- 標題同時焊住**事件 + 關係 / 場域**："外賣員送錯一單，送進了自己的董事會"。
- 不劇透結局，不用和正文不符的封面（會拉高跳出率、傷賬號）。
- 同一集準備 2-3 版封面 / 標題，用資料選（見下）。

## 9. 用資料迭代

可看的指標（各平台後臺名稱不同）：
- **前 2-3 秒跳出率 / 划走率**：高 → 鉤子不夠，換第一幀或第一句。
- **平均觀看時長 / 完播率**：低 → 看留存曲線在哪一秒掉。
- **留存曲線的陡降點**：對到分鏡表的那一條、那一秒，通常是鋪墊過長、空看、資訊重複。
- **互動（評論、轉發）**：看觀眾在討論哪句臺詞、哪個反轉，下一集加碼。
- **點選率（封面 / 標題）**：多版封面對比。

迭代方法：
1. 每集釋出後記錄：標題、封面版本、時長、前 3 秒內容、各指標。
2. 找留存曲線陡降的秒數 → 對應分鏡表 → 記一條"下次不要這樣寫"的規則。
3. 一次只改一個變數（只換開頭、或只換封面），否則看不出是哪個起作用。
4. 把有效寫法沉澱回本包的模板和規則。
5. 資料只用真實後臺資料，不編、不估。

## 10. 可抄清單

1. 第一幀有動作或臺詞，第一個字在 1 秒內出現。
2. 30 秒內落一個不可逆事實。
3. 每 10-20 秒一個小兌現。
4. 每個前置道具都在後面用上。
5. 集尾停在新問題出現的瞬間。
6. 封面 = 本集最強衝突幀 + 3-8 字懸念。
7. 標題焊住事件 + 關係。
8. 每集記錄資料，一次只改一個變數。
