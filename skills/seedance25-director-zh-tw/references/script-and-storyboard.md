# 劇本 → 分鏡 → 生成單元

## 1. 劇本層（可拍的劇本）

每場寫：
- 場號、地點、時間（光色）、在場人物
- **這場的作用**（推進哪件事、兌現什麼）
- 動作（只寫鏡頭看得見的）
- 對白（逐字，標說話人和聲線）

規則：
- 只寫看得見、聽得見的東西，不寫心理活動；心理用動作或臺詞表達。
- 每場只推進一件事。
- 鉤子前置，集尾留問題（見 `viral-hooks.md`）。
- 每個道具、動作都要有理由，後面要用上。
- 模板：`../templates/episode-script.md`。

## 2. 分鏡層

把劇本拆成鏡頭：每個鏡頭寫景別、機位（在軸線哪一側）、運鏡（一個）、動作、臺詞、聲音、開場接哪一幀、結束狀態。

- 模板：`../templates/storyboard-table.md`。
- 每個鏡頭的"開場"必須和上一鏡的"結束"對得上（見 `continuity.md`）。
- 標出這個鏡頭的兌現點在第幾秒。

## 3. 生成單元層

一條提示詞 = 一個生成單元：
- 10 秒單元：1 個鏡頭或 2 個鏡頭（3-4s + 6-7s）。
- 9-15 秒：2-4 個鏡頭。
- 15-30 秒：長條，見 `long-takes.md`。

合併規則：同一連續時空、同一組人物、動作簡單的相鄰鏡頭 → 合併成一條；人多、動作複雜、換場 → 拆開。

模板：`../templates/script-to-shots.md`。

## 4. 每條提示詞交付前

- [ ] 節拍表（秒段 / 景別 / 動作 / 臺詞 / 聲音）
- [ ] 參考圖掛載順序
- [ ] 字元數 ≤ 平台上限（`scripts/count_chars.sh`）
- [ ] 沒有 still / as before / 舊版本指代
- [ ] 沒有刻意象徵動作
- [ ] 禁音樂 / 禁字幕 寫了兩次
- [ ] 預算算過，等待確認

## 5. 複雜排程

人多、走位複雜、運鏡精確的場：先用白模 / 3D 預演定機位，掛預演影片作為運鏡參考，再寫提示詞。
