# 後期

## 1. 剪死尾巴

- 模型常在結尾留幾秒空看、或鏡頭停在無意義構圖上。QC 時記下出點，剪掉。
- 出點同時就是下一鏡的銜接幀時間（`scripts/cut_frame.sh`）。
- 開頭如果有 0.5-1 秒的"起勢"也可以剪，讓第一幀就有動作。

## 2. 靜音模型配樂

即使寫了 no music，模型仍可能加鋼琴。處理順序：
1. 單條片段裡音樂和對白混在一起時，用人聲分離工具把人聲 + 環境聲留下（效果因片而異，處理後回聽）。
2. 無對白片段可以直接靜音，後期另鋪環境聲。
3. 整集統一後期配樂（如需要），保證音樂連貫。

```bash
# 只要畫面、去掉全部音軌
ffmpeg -i in.mp4 -c:v copy -an out_silent.mp4
# 裁剪（重新編碼，幀精確）
ffmpeg -i in.mp4 -ss 0 -to 6.0 -c:v libx264 -crf 18 -c:a aac out_trim.mp4
```

## 3. 響度

- 全集統一響度（短影片平台常見目標約 -14 LUFS 左右，以平台規範為準）：
  `ffmpeg -i in.mp4 -af loudnorm=I=-14:TP=-1.5:LRA=11 -c:v copy out.mp4`

## 4. 燒錄字幕

- **字幕不加標點**：句中用空格斷開，句末不加句號。問號、感嘆號也去掉，語氣靠斷行。
- 大字號、高對比、描邊或底框；豎屏放在畫面下 1/3 以上，避開平台右側按鈕和底部文案區。
- 一行不超過約 12-16 個漢字或 32-40 個英文字元（經驗值）。
- 外語劇出中文或英文字幕時，按分鏡表裡的翻譯對時間軸。
- 提示詞裡永遠寫"不要字幕"，字幕只在後期加。

## 5. 封面

- **豎屏 9:16**（YouTube Shorts、抖音、Reels 都用豎版封面）；橫屏片另做 16:9。
- 用成片裡最強的一幀（表情最大、衝突最清楚的瞬間），或用圖片模型按定妝照重做高畫質版。
- 封面大字 3-8 個字，寫衝突或懸念，不劇透結局；字放在中上部，避開平台 UI。
- 封面人物也必須和定妝照一致。
- 更多見 `viral-hooks.md` 的"封面與標題"。

## 6. 橫豎轉換

- 9:16 → 16:9 直接裁會丟頭腳；需要兩種畫幅時**分別生成**，或生成時保留安全區（主體居中，上下留空）。
- 參賽片要求 16:9 時，從分鏡階段就按 16:9 設計構圖（見 `formats-and-budget.md`）。

## 7. 交付清單

- 成片（最高解析度）+ 小體積預覽版
- 封面（對應畫幅）
- 字幕檔案（SRT，供平台自動字幕或翻譯）
- 鏡頭清單與參考圖清單（便於複用）
