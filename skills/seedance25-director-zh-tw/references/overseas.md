## Vigloo Studio【團隊實測】

**節點與操作**
- 畫布裡建 Seedance 2.5 影片節點：9:16、720p、時長滑桿 4-20 秒、音訊開（原生對白 + 環境聲）。
- 右鍵選單：**Extend Video**（Seedance 2.5 Edit，最短 5 秒，約 300 積分）、**Edit Video**（約 420 積分）、**Extract frame**。**沒有 Trim**，剪輯放到後期。
- 不要重新整理畫布（會丟未儲存狀態或重複提交）。

**真人臉政策（最重要）**
- 上傳圖片或首尾幀裡出現**真人臉（包括 AI 生成的寫實人臉）會被拒**。
- 所以：角色只能走**已註冊的 Character 節點**；首幀用**空場底板**（不含人）；場景、道具走參考圖。
- 提示詞裡**只用 `@Name` chip 或 `@image1` 指代，不再用文字描寫長相**（文字描寫會和角色節點衝突）。
- `@` 前面要有空格；`@` 選單隻列出**已連線**的節點。
- 聲音鎖定：掛一段 mp3 作為 `@audio1`，寫"音色按 @audio1"。不想讓某角色出鏡但要他的聲音時，不掛他的角色節點，只掛音訊。
- 典型掛載：1 張場景/道具參考 + 2 個角色節點（+ 可選 1 段音訊）。

**寫法**
- 逐秒節拍，12-20 秒寫 4-6 個節拍。
- 方向寫死並帶否定（團隊踩過"走反方向"的坑）："她朝盡頭的安全門跑，背對鏡頭，不是朝鏡頭跑"。
- 長條裡道具會瞬移、追逐動作會被省略 → 道具位置每拍重申，追逐拆短拍。
- 審核規避：不寫 血 / 屍體 / 殺 / 槍；不做肢體打鬥接觸（"兩者之間始終留出空當，沒有任何身體接觸"）。
- 固定結尾句：`只有指定角色說話，其他人不說話。原生環境音效照實生成，不要背景音樂，不要配樂，不要字幕，不要任何文字水印。`
- 模板：`../templates/canvas-prompt-overseas.md`；樣例：`../examples/overseas-vigloo-20s-ko.md`。

## TapNow【團隊實測】

- 畫布影片節點選 Seedance 2.5，用 **Omni Reference**，開啟 `generate_audio`。
- 480p 一條 28 秒長鏡頭約 560 Tapies；成片按 16:9 輸出過（預告片）。
- **影片續拍**：把上一條已透過的影片作為 `{{Video}}` 參考掛上，再寫接續提示詞。
- 提示詞長度：實際接受過 14,676 字元；團隊後來定的規矩是**純 ASCII、≤ 2000 字元**，更穩。
- **同一條只點一次 Generate**；重新整理頁面或雙擊會重複扣費。
- 已提交的付費任務不要中途取消。

## Higgsfield

**官方（higgsfield.ai/seedance-2.5 與 API 文件，2026-11 讀取）【官方】**
- 單次 4-30 秒；音訊預設開啟，可關。
- 參考最多 50 個：圖片 30、影片 10、音訊 10。
- 畫幅：21:9、16:9、4:3、1:1、3:4、9:16。
- API 解析度檔：480p / 720p / 1080p；網頁端另有 4K（官方 Threads 2026-11-14 公告上線）。
- 另有 Seedance 2.5 Edit（區域性修改）和 Seedance 2.5 Extend（續寫）。
- 官方建議：提交前看 Generate 按鈕上顯示的積分。

**團隊記錄**
- 720p · 9:16 · 5 秒 = 35 credits（約 7/秒）【團隊實測】；1080p / 4K 價格未實測。
- 有 480p 草稿再定稿的 Draft 模式【第三方：測評文章稱 2026-09 上線、美國區不可用】，未實測。
- 團隊 2026-11 檢視官方模型目錄時，Elements（`<<<element_id>>>` 佔位）支援列表裡沒有 Seedance 2.5 → 角色先用原始定妝照做 image reference，不依賴 Elements；Soul ID 能否驅動 2.5 未實測。
- 首幀 start_image 會鎖死整張畫面，不只是機位；只在需要第一幀完全一致時用。

## API 渠道（團隊調研，官方定價頁，2026-11）

- BytePlus / Replicate / OpenRouter / fal 等都有 Seedance 2.5 按量計費，價格隨時變，用前開啟官方定價頁核對。
- API 引數名、上限以各家文件為準；金鑰放環境變數，**絕不寫進倉庫**。

## 海外平台寫法要點

- 英文劇用英文寫；美劇對白統一 **American accent**。
- 畫布平台優先用 chip 指代，chip 之外的文字只寫動作、機位、聲音。
- 人臉政策嚴的平台（Vigloo）走角色節點 + 空場首幀；人臉政策寬的平台（Higgsfield 網頁）可直接用原始定妝照。
