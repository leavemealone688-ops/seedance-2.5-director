# 爆款结构：钩子、留存、反转、结尾与数据迭代

> 本节的秒数和比例是竖屏短剧行业的常见经验，不是平台公布的标准。用你自己的后台数据校准（见第 7 节）。

## 1. 一句话定位先于一切

写剧本前先写一句：`题材标签 × 核心拧点`。拧点是**本剧真正的期待句**，不是"打脸逆袭"这种陈词：
- "每晚十二点准时来电的号码，是她十年前注销的手机"
- "全村只有她看得见那口井，而井里的人在叫她的名字"

标题、封面、第一句台词都要从这句里长出来。

## 2. 前 1-3 秒钩子

第一帧就要有事。可用的钩子类型：

| 类型 | 例子 | 提示词怎么写 |
|---|---|---|
| 冲突已发生 | 一巴掌刚落下、离婚协议已按印 | `0-1s: open mid-action, …` 不写起势 |
| 视觉奇观 | 地面裂成深渊、一屋子人同时回头 | 第 0 秒就是奇观的最大画面 |
| 反常识台词 | "婚礼取消了，新郎是我爸" | 台词放在 0-2s，第一个字就开口 |
| 危险倒计时 | 手指离印泥只差毫厘 | 特写 + 极慢推 |
| 身份落差 | 外卖员被当众叫成"董事长" | 先给落差画面再给反应 |
| 悬念物件 | 一张空白的降书、一只不响的铃 | 道具特写开场 |

忌：空镜开场、慢慢走进来、天空建立镜头、片头字卡。

## 3. 前 30 秒必须落地的事

- 一个**不可逆事实**：按了手印、禁忌已触发、死局已成。
- 一个**信息差**：观众知道而戏里人不知道（或反过来），这是追看的燃料。
- 主角的**目标**清楚，阻力露出第一层。

## 4. 留存节奏

- 每 10-20 秒给一个**小兑现或小反转**（新信息、局势变化、一句狠话），不要连续 20 秒以上纯铺垫。
- 疏密对比：冲突段短镜快切，情绪落点给 1-2 秒呼吸。
- 每场戏只推进一件事；同一信息不重复交代。
- 对白短：一句一个信息，能用动作交代的不说。
- 生成层面：一条 10-20 秒的提示词对应一个"小兑现单元"，节拍表里标出每个兑现点在第几秒。

## 5. 反转与兑现

- **埋设 → 兑现**：前面出现的道具 / 台词 / 能力，后面必须用上（例：开场一只不响的铃 → 集尾它自己响了一声报警）。
- 反转要有前置线索，回看能对上；没有线索的反转观众会觉得被骗。
- 可计量的爽点：按题材选计量方式（战力对比、知情人数、倒计时、具体体贴的次数），每集至少兑现一次。
- 反转镜头的拍法：先给反应，再给原因；或者先给原因的一半，让观众先猜。

## 6. 结尾钩子与 CTA

集尾钩子类型：
- 威胁未解（门外的人还在拍门）
- 身份将揭（她抬头看向那盏灯）
- 误会加码
- 资源将得 / 将失
- 糖后必险（温情之后一个不安的细节）

规则：
- 集尾追看主问要和开场定位同根，不要中途换成无关问题。
- 结尾停在**问题刚被提出**的那一帧，不要停在答案后的空看。
- CTA（关注、看下集）放在成片外的文案或片尾 1 秒字卡，不要让角色对镜头说"记得关注"，会破坏代入感。
- 提示词层面：最后一段写到"问题出现"的动作为止，结尾 0.5 秒可写"画面静止"给剪辑留出点。

## 7. 竖屏短剧单集结构（参考）

| 段落 | 时长占比（经验） | 内容 |
|---|---|---|
| 钩子 | 前 3 秒 | 冲突 / 奇观 / 反常识台词 |
| 建立 | 到 15-20 秒 | 不可逆事实 + 信息差 + 目标 |
| 推进 | 中段 | 2-3 个小兑现 / 小反转 |
| 高点 | 后 1/4 | 本集最大的兑现或反转 |
| 集尾钩 | 最后 3-5 秒 | 新问题 |

拆到生成单元：每 10-20 秒一个单元，每单元一个节拍表（见 `../templates/script-to-shots.md`）。

## 8. 封面与标题

- 封面：9:16，用最强冲突帧或重做高清版；大字 3-8 个字，写冲突或悬念；人物脸大、表情清楚；字避开平台 UI。
- 标题同时焊住**事件 + 关系 / 场域**："外卖员送错一单，送进了自己的董事会"。
- 不剧透结局，不用和正文不符的封面（会拉高跳出率、伤账号）。
- 同一集准备 2-3 版封面 / 标题，用数据选（见下）。

## 9. 用数据迭代

可看的指标（各平台后台名称不同）：
- **前 2-3 秒跳出率 / 划走率**：高 → 钩子不够，换第一帧或第一句。
- **平均观看时长 / 完播率**：低 → 看留存曲线在哪一秒掉。
- **留存曲线的陡降点**：对到分镜表的那一条、那一秒，通常是铺垫过长、空看、信息重复。
- **互动（评论、转发）**：看观众在讨论哪句台词、哪个反转，下一集加码。
- **点击率（封面 / 标题）**：多版封面对比。

迭代方法：
1. 每集发布后记录：标题、封面版本、时长、前 3 秒内容、各指标。
2. 找留存曲线陡降的秒数 → 对应分镜表 → 记一条"下次不要这样写"的规则。
3. 一次只改一个变量（只换开头、或只换封面），否则看不出是哪个起作用。
4. 把有效写法沉淀回本包的模板和规则。
5. 数据只用真实后台数据，不编、不估。

## 10. 可抄清单

1. 第一帧有动作或台词，第一个字在 1 秒内出现。
2. 30 秒内落一个不可逆事实。
3. 每 10-20 秒一个小兑现。
4. 每个前置道具都在后面用上。
5. 集尾停在新问题出现的瞬间。
6. 封面 = 本集最强冲突帧 + 3-8 字悬念。
7. 标题焊住事件 + 关系。
8. 每集记录数据，一次只改一个变量。
