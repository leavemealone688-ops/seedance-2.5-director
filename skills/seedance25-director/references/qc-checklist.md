# 出片 QC 清单

## 先做两件事

```bash
scripts/contact_sheet.sh S03_v1.mp4 S03_v1_contact.png 2 5   # 每秒 2 帧联系表
scripts/contact_sheet.sh S03_v1.mp4 S03_v1_hands.png 6 6     # 每秒约 6 帧，专查手指和穿模
```
然后**完整听一遍声音**（对白、口型、有没有配乐）。

## 清单

**角色**
- [ ] 脸与定妆照一致（每个角色单独看，尤其入画那一秒）
- [ ] 发型轮廓、发色、服装、配饰、硬记号一致；没有多出禁止饰品
- [ ] 服装状态对（赤脚 / 淋湿 / 脱外套）
- [ ] 人数对；没有多出路人

**身体**
- [ ] 手指五根，没有融合
- [ ] 没有人和桌椅 / 车 / 动物穿模；配件（背带、链子）没粘在物体上
- [ ] 动作方向对

**空间与连续性**
- [ ] 开场和上一镜衔接帧一致：机位侧、景别、站位、光色
- [ ] 人物左右没互换，银幕方向一致
- [ ] 道具位置、数量、状态对
- [ ] 背景没新增门、灯、设备；文字没乱码（或可接受）
- [ ] 背景人物在动

**声音**
- [ ] 台词完整、逐字正确、说话人正确
- [ ] 口型对得上；不说话的人没动嘴（查末帧）
- [ ] 没有怪声（喘气、尖叫）
- [ ] 有没有模型自带音乐（有 → 后期静音）

**节奏与表演**
- [ ] 没有刻意象征动作、没有对着镜头凝视
- [ ] 结尾空看多长 → 记下剪辑出点
- [ ] 镜头有没有停在无意义的构图上（例如长时间只拍下半身）

**技术**
- [ ] 时长、画幅、分辨率对（`ffprobe`）
- [ ] 硬切是否出现在不该切的地方
- [ ] 细纹理（岩石、水面、树叶、布料、头发等）清晰，没有块状 / 网格状压缩伪影

## 结论格式

`留用 / 留用需剪（出点 x.x s，静音配乐）/ 重跑（原因 + 改哪句）`，记进分镜表的镜头记录。模板：`../templates/qc-report.md`。
