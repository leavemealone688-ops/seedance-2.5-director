## Vigloo Studio【团队实测】

**节点与操作**
- 画布里建 Seedance 2.5 视频节点：9:16、720p、时长滑杆 4-20 秒、音频开（原生对白 + 环境声）。
- 右键菜单：**Extend Video**（Seedance 2.5 Edit，最短 5 秒，约 300 积分）、**Edit Video**（约 420 积分）、**Extract frame**。**没有 Trim**，剪辑放到后期。
- 不要刷新画布（会丢未保存状态或重复提交）。

**真人脸政策（最重要）**
- 上传图片或首尾帧里出现**真人脸（包括 AI 生成的写实人脸）会被拒**。
- 所以：角色只能走**已注册的 Character 节点**；首帧用**空场底板**（不含人）；场景、道具走参考图。
- 提示词里**只用 `@Name` chip 或 `@image1` 指代，不再用文字描写长相**（文字描写会和角色节点冲突）。
- `@` 前面要有空格；`@` 菜单只列出**已连线**的节点。
- 声音锁定：挂一段 mp3 作为 `@audio1`，写"音色按 @audio1"。不想让某角色出镜但要他的声音时，不挂他的角色节点，只挂音频。
- 典型挂载：1 张场景/道具参考 + 2 个角色节点（+ 可选 1 段音频）。

**写法**
- 逐秒节拍，12-20 秒写 4-6 个节拍。
- 方向写死并带否定（团队踩过"走反方向"的坑）："她朝尽头的安全门跑，背对镜头，不是朝镜头跑"。
- 长条里道具会瞬移、追逐动作会被省略 → 道具位置每拍重申，追逐拆短拍。
- 审核规避：不写 血 / 尸体 / 杀 / 枪；不做肢体打斗接触（"两者之间始终留出空当，没有任何身体接触"）。
- 固定结尾句：`只有指定角色说话，其他人不说话。原生环境音效照实生成，不要背景音乐，不要配乐，不要字幕，不要任何文字水印。`
- 模板：`../templates/canvas-prompt-overseas.md`；样例：`../examples/overseas-vigloo-20s-ko.md`。

## TapNow【团队实测】

- 画布视频节点选 Seedance 2.5，用 **Omni Reference**，打开 `generate_audio`。
- 480p 一条 28 秒长镜头约 560 Tapies；成片按 16:9 输出过（预告片）。
- **视频续拍**：把上一条已通过的视频作为 `{{Video}}` 参考挂上，再写接续提示词。
- 提示词长度：实际接受过 14,676 字符；团队后来定的规矩是**纯 ASCII、≤ 2000 字符**，更稳。
- **同一条只点一次 Generate**；刷新页面或双击会重复扣费。
- 已提交的付费任务不要中途取消。

## Higgsfield

**官方（higgsfield.ai/seedance-2.5 与 API 文档，2026-11 读取）【官方】**
- 单次 4-30 秒；音频默认开启，可关。
- 参考最多 50 个：图片 30、视频 10、音频 10。
- 画幅：21:9、16:9、4:3、1:1、3:4、9:16。
- API 分辨率档：480p / 720p / 1080p；网页端另有 4K（官方 Threads 2026-11-14 公告上线）。
- 另有 Seedance 2.5 Edit（局部修改）和 Seedance 2.5 Extend（续写）。
- 官方建议：提交前看 Generate 按钮上显示的积分。

**团队记录**
- 720p · 9:16 · 5 秒 = 35 credits（约 7/秒）【团队实测】；1080p / 4K 价格未实测。
- 有 480p 草稿再定稿的 Draft 模式【第三方：测评文章称 2026-09 上线、美国区不可用】，未实测。
- 团队 2026-11 查看官方模型目录时，Elements（`<<<element_id>>>` 占位）支持列表里没有 Seedance 2.5 → 角色先用原始定妆照做 image reference，不依赖 Elements；Soul ID 能否驱动 2.5 未实测。
- 首帧 start_image 会锁死整张画面，不只是机位；只在需要第一帧完全一致时用。

## API 渠道（团队调研，官方定价页，2026-11）

- BytePlus / Replicate / OpenRouter / fal 等都有 Seedance 2.5 按量计费，价格随时变，用前打开官方定价页核对。
- API 参数名、上限以各家文档为准；密钥放环境变量，**绝不写进仓库**。

## 海外平台写法要点

- 英文剧用英文写；美剧对白统一 **American accent**。
- 画布平台优先用 chip 指代，chip 之外的文字只写动作、机位、声音。
- 人脸政策严的平台（Vigloo）走角色节点 + 空场首帧；人脸政策宽的平台（Higgsfield 网页）可直接用原始定妆照。
