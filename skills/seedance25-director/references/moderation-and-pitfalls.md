# 审核与常见坑

## 审核规避写法

| 类型 | 写法建议 |
|---|---|
| 血、伤口、医疗操作 | `no blood, no medical procedure`；伤口用"干净的绷带"；不拍手术过程 |
| 武器 | 能不出现就写"不出现武器"；必须出现时只给剪影或一道光 |
| 火、爆炸 | 用光色暗示；"不出现明火"；奇幻火光写成"暗红暗橙的光"而非燃烧的人 |
| 打斗 | 不写殴打、踩人特写；改成"手按手腕"等克制动作；"两者之间始终留出空当，没有任何身体接触"；脚和靴子不入画 |
| 敏感词 | 中文避免：血 / 尸体 / 杀 / 枪 / 死；用"倒下""不动了""红色液体也不要" |
| 真人、品牌、logo | 不写真人名字；车、衣服、招牌写"no logos, no lettering" |
| 未成年人 | 避免任何敏感情境 |
| 历史 / 政治 | 架空处理，不影射现实政治 |
| 暴露 | 服装写清楚完整 |
| 真人脸参考（海外画布） | Vigloo 拒收含写实人脸的上传图 → 走 Character 节点 + 空场首帧 |

安全句：
- `No weapons, no blood, no fire, no medical procedure. No text on screen.`
- `不出现武器、血迹、明火。画面中不要任何文字、字幕、水印。`

## 被拒后的顺序

1. 小云雀"视频可能不合规"：**原样重试**（团队经验：会退积分，常能通过）。
2. 仍被拒：找最可能的敏感词换成克制写法，记录改了哪里，先告诉负责人。
3. 参考图本身也可能触发（伤口、武器道具图），必要时换图。

## 生成质量的坑（团队实测）

| 坑 | 原因 / 现象 | 对策 |
|---|---|---|
| 跑脸 | 用了生成截帧当脸部参考 | 只用原始定妆照 |
| 人和桌子 / 椅子穿模 | 多人入座、躯干与桌沿融合 | 写"solid, physically correct contact"；首帧先查；人少一点 |
| 手指数量不对 | 手部动作复杂、特写 | 写"natural hands with five fingers"；手部动作放中景、做简单握拳/握腕；按约 6fps 抽帧数手指 |
| 网格 / 块状伪影 | 碎石、草叶、地毯等细纹理 | 按场景点名画面里实际有的细纹理并要求"细节清晰锐利，没有块状或网格状压缩伪影"（见 `universal-rules.md` 第 9 节）；降低细纹理占画面比例；景别稍近；轻微的可接受，否则重跑 |
| 背景人物定住 | 没写背景动作 | 写自然小动作，"they stay in place" |
| 背景乱码招牌 | 模型自造文字 | 写"plain, blank, no lettering"；用运镜避开 |
| 道具瞬移 / 数量变化 | 长条里尤甚 | 每拍重申位置和"只有这一只" |
| 追逐动作被省略 | 长条里动作太多 | 拆短拍，每拍一个动作 |
| 走反方向 | 方向描述模糊 | 写死方向并加否定 |
| 多出的切镜 | 写了 SHOT/CUT 标签或时间段太满 | 删标签、减内容 |
| 不该说话的人张嘴 | 没写闭嘴 | `mouth stays closed, no lip movement`；QC 查末帧 |
| 自带钢琴 / 配乐 | 模型习惯 | 禁音乐写两遍 + 后期静音 |
| 结尾空看 | 时间线末段太空 | 末段只给 1 秒，后期裁 |
| 刻意象征动作 | 提示词写了仪式性动作 | 删掉，见 `acting-and-pacing.md` |
| 某角色不露脸的要求被破坏 | 每段都要重申 | 每段重写"背对镜头 / 脸在画框外" |

## 操作纪律

- 同一条只点一次生成；不要刷新画布或双击（TapNow / Vigloo 会重复扣费）。
- **已提交的付费任务不要中途取消**。
- 一次只跑一条，确认通过再跑下一条；不要并发重复提交。
- 每次提交前把"平台、参数、参考顺序、预计花费"列给负责人，得到同意再提交。
