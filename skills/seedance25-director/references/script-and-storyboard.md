# 剧本 → 分镜 → 生成单元

## 1. 剧本层（可拍的剧本）

每场写：
- 场号、地点、时间（光色）、在场人物
- **这场的作用**（推进哪件事、兑现什么）
- 动作（只写镜头看得见的）
- 对白（逐字，标说话人和声线）

规则：
- 只写看得见、听得见的东西，不写心理活动；心理用动作或台词表达。
- 每场只推进一件事。
- 钩子前置，集尾留问题（见 `viral-hooks.md`）。
- 每个道具、动作都要有理由，后面要用上。
- 模板：`../templates/episode-script.md`。

## 2. 分镜层

把剧本拆成镜头：每个镜头写景别、机位（在轴线哪一侧）、运镜（一个）、动作、台词、声音、开场接哪一帧、结束状态。

- 模板：`../templates/storyboard-table.md`。
- 每个镜头的"开场"必须和上一镜的"结束"对得上（见 `continuity.md`）。
- 标出这个镜头的兑现点在第几秒。

## 3. 生成单元层

一条提示词 = 一个生成单元：
- 10 秒单元：1 个镜头或 2 个镜头（3-4s + 6-7s）。
- 9-15 秒：2-4 个镜头。
- 15-30 秒：长条，见 `long-takes.md`。

合并规则：同一连续时空、同一组人物、动作简单的相邻镜头 → 合并成一条；人多、动作复杂、换场 → 拆开。

模板：`../templates/script-to-shots.md`。

## 4. 每条提示词交付前

- [ ] 节拍表（秒段 / 景别 / 动作 / 台词 / 声音）
- [ ] 参考图挂载顺序
- [ ] 字符数 ≤ 平台上限（`scripts/count_chars.sh`）
- [ ] 没有 still / as before / 旧版本指代
- [ ] 没有刻意象征动作
- [ ] 禁音乐 / 禁字幕 写了两次
- [ ] 预算算过，等待确认

## 5. 复杂调度

人多、走位复杂、运镜精确的场：先用白模 / 3D 预演定机位，挂预演视频作为运镜参考，再写提示词。
