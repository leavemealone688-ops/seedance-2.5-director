# Complete Consistency Handbook

Consistency isn't just faces. Viewers drop out because a cup changes hands, a sign changes text, or the light jumps from gold back to blue. For each category below: **what to lock, how to write it, how to check it**.

Principle: **consistency comes from four things — asset bible + restating in every prompt + continuity frame + QC** — not from the model's memory. Asset bible: `../templates/asset-bible.md`.

---

## 1. Characters (face / hair / build / wardrobe / accessories / hard marks)

See `character-lock.md`. Pattern:

```
Image 1 is <label>: same face, same <hair silhouette + color>, same <build/age>, same <top>, same <bottom>, same <shoes>, same <accessories>. No <forbidden accessories>.
```
Chinese:
```
@图片1 是<称呼>：脸、<发型>、<服装>、<配饰>严格按此图，不戴戒指，不戴眼镜。
```

## 2. Wardrobe continuity (states that change)

Track wardrobe state along the scene timeline: dry → soaked, shoes → barefoot, coat on → off, white shirt → mud-splashed.

- Open every prompt with the **current state**, present tense: "she is already barefoot", "his shirt is soaked dark at the shoulders".
- A state change happens once, inside one shot, at a stated second: "3-5s: she slips off her flats".
- Later shots all say "already" in the new state; update the "wardrobe state" column in the asset bible.
- Big changes (a whole new outfit) get a new state portrait with a suffix: `C01-EDNA_barefoot`.

## 3. Scenes (layout / spatial anchors / set dressing / signage)

**Lock the layout**: each main location gets a main plate + a reverse plate, with anchors spelled out: which side the door is, which side the window, main furniture, exit direction.

Pattern:
```
Same <location>: <left anchor> on the left, <right anchor> on the right, <depth anchor> at the far end, exactly as in Image 3.
楼道空间、与墙齐平的木门、右手玻璃幕墙、尽头灰色安全出口门，一律按 @图片1。
```

- **Set dressing**: list the key items ("a cut white cake just left of the lilies; only the blonde woman has a full cup of tea"); leave the rest to the plate.
- **Signage and text**: background text generated by the model often comes out garbled.
  - Text you don't need: `the wall and door are plain and blank, no signs, no lettering of any kind`; or move signs out of frame with the camera.
  - Text you need (tombstone, text message, a written decree): let the model generate it, write "legible, undistorted lettering", and attach a prop image with the correct text; numeric info (counters, clocks) is safer as a post overlay.
- **Doors / devices appearing**: long clips sprout lights, screens, peepholes on doors → "the door has only a push bar; no lights, screens or electronics appear at any point".

## 4. Props and prop states

A prop has **position, holder and state** — any of which can change per beat.

- Keep a prop state table: `prop | who holds it / where | state (full/empty, open/closed, intact/broken) | from which second`.
- Each beat states the prop's end state: "End state: the bill is in her closed hand, resting in her lap."
- Lock hand-off order: "Only after hearing this, she reaches into her pocket…"
- Uniqueness: "only this one bell throughout"; repeat for props that tend to multiply.
- Props **teleport** in long clips (Vigloo team, tested) → restate position every beat.
- Give props their own reference image: "the prop looks exactly like @图片3".

## 5. Light / color temperature / time of day

- Each scene gets **one Kelvin value + a light source**: "cool misty morning, about 4800K, soft overcast light"; night scenes: "only the practical lights in the set".
- Write a light change as an event in the timeline, and say "natural change, no supernatural effect": "the light warms naturally to 3200K gold over 4 seconds".
- After the change, later shots carry "warm gold holds throughout, never jumping back to cool blue".
- The continuity frame carries the color; the prompt also states the number so they confirm each other.
- Time of day (dawn / dusk / late night) goes in the asset bible and doesn't jump between shots.

## 6. Camera axis / 180-degree rule / screen direction

- Each scene defines an **axis** (the line between the two main characters) and **which side the camera stays on**; record it: "all shots from the pickup's right side".
- Every prompt: "on the same camera side of the truck as Image 4".
- **Screen direction**: if a character walks left to right, the next shot continues left to right; write "walks toward frame right".
- Shot / reverse-shot: A at frame left looking right, B at frame right looking left; eyelines explicit: "eyeline clearly on him, to the right of frame".
- Cross the line only when the script needs it, via a bridge shot (neutral angle, a character's move carries it).

## 7. Weather and ambience

- Weather is a state: rain intensity, fog, wind, ground wetness — restate each prompt. "Heavy rain keeps splashing on the stone table."
- Ambience follows weather: rain, wind, distant thunder; rain stopping must be written as an event.
- Background people need small natural moves ("background mourners shift weight, slight head turns, they stay in place"), or they freeze.

## 8. Cross-episode consistency

- One **character bible** for the whole series: portraits, hard-mark text, voice description, forbidden accessories. Paste the hard-mark text verbatim into every prompt.
- Reuse the same main and reverse plates; renovations or season changes get a new version with a suffix.
- Voice: the same voice description every episode; on overseas canvases, the same `@audio1`.
- "Previously on" shots never use last episode's frames as face references.

## 9. Asset library and naming

```
assets/
  characters/  C01-EDNA_front.png  C01-EDNA_side.png  C01-EDNA_barefoot.png
  scenes/      S01-CLINIC_main.png  S01-CLINIC_reverse.png
  props/       P01-BELL.png  P02-LETTER_blank.png  P02-LETTER_signed.png
  audio/       V01-COLE_voice_3s.mp3
episodes/EP01/
  shots/  S03_v1_prompt.txt  S03_v1.mp4  S03_v1_contact.png  S03_v1_cut.png
```

- Once confirmed, IDs are never reused; state variants get a suffix, the original stays untouched.
- Record each prompt's reference order in the storyboard, e.g. `1=C01-EDNA_front / 2=C02-COLE_front / 3=A01-DOG / 4=EP01_S02_v2_cut`.
- Shot versions use `_v1 _v2`; mark the keeper "locked" in the storyboard.

## 10. Consistency QC (every render)

- Face, hair, wardrobe, accessories vs. the portrait, item by item (contact sheet).
- Prop position, count and state match the prop table.
- Color matches the previous continuity frame — no jumps.
- Camera on the same side, left/right not swapped, screen direction kept.
- No new doors, lights, devices; no garbled text.
- See `qc-checklist.md`.
