## 샤오윈췌 (주력 플랫폼)

**작업 순서 [팀 실측]**
1. `https://www.xiaoyunque.com/home`을 열고 영상 입력창에서 바로 시작합니다. 프로젝트를 먼저 만들 필요는 없습니다.
2. Seedance 2.5 → 参考生成 → 화면비 → 10s → 720P 선택.
3. **목록 순서대로 레퍼런스를 올립니다**. 업로드 순서가 곧 `图片1…N`입니다. 보통 4장: 캐릭터 기준 이미지(주인공 먼저) → 동물·핵심 소품 → 연결 프레임(마지막). 플랫폼 최대 장수는 미검증(모델 자체의 공식 상한은 이미지 30장, `sources.md` 참고. 단 프런트엔드는 더 적을 수 있음).
4. 프롬프트 붙여넣기 — **하드 제한 5000자** [팀 실측]. 크레딧 확인 후 제출.
5. 생성에 약 5~10분. 제출 후 10분쯤 뒤에 확인합니다. 카드에 마우스를 올리고 다운로드 아이콘으로 저장.
6. `qc-checklist.md`로 QC.

**기타 기록**
- 영상 레퍼런스를 붙이면 10초당 약 260 크레딧 예정, 결제 확인 화면 기준(완전 검증 아님).
- 1080P: 리서치 메모에 샤오윈췌가 2026-08-14 1080P를 출시했다고 기록 [제3자 전언], 가격은 미검증.
- 초기 회차는 SEG_A / SEG_B / SEG_C로 나눠 생성: 앞 구간이 통과해야 다음 구간을 돌렸습니다.
- 멤버십 크레딧은 매월 갱신(날짜는 계정 페이지 확인).

**"视频可能不合规"(영상이 규정에 맞지 않을 수 있음)**
- 증상: 생성이 끝나면서 이 안내가 뜨고 영상이 나오지 않음.
- 대처: **입력을 하나도 바꾸지 말고 그대로 다시 제출**. 우리 경험상 이런 반려는 크레딧이 환불되고, 그대로 재시도하면 통과하는 경우가 많습니다.
- 여러 번 연속 반려될 때만 민감어를 찾고(`moderation-and-pitfalls.md`), 바꾸기 전에 담당자에게 먼저 알립니다.

**자주 나오는 부작용**
- 모델이 피아노·배경음악을 자주 넣음 → `no music, no piano, no harp, no score`라고 쓰고, 후반에서도 음소거.
- 배경 간판 글자가 깨짐 → "건물 외벽에 간판·글자 없음"이라고 쓰거나 카메라 무빙으로 간판을 화면 밖으로. 약하게 깨진 정도는 후반에서 판단.
- 끝에 몇 초씩 멍하니 응시 → 마지막 비트에 1초("한 번 숨 쉬기")만 주고 후반에서 자름.

**브라우저를 여럿이 쓸 때**: 자기 탭만 건드리고, 생성 중에는 페이지를 닫거나 이미 과금된 작업을 취소하지 않습니다.

## LibTV (liblib.tv)

- 캔버스에서 Seedance 2.5「全能参考」노드 선택 [팀 실측].
- **CLI로 제출하면 정가로 차감되고, 할인·무료 크레딧은 웹과 앱 제출에만 적용** [팀 실측]. CLI로 대량 돌리기 전에 계산해 둡니다.
- 30초 1개 차감 기록은 있지만 멀티컷 전환 품질은 체계적으로 평가하지 않았습니다.
- 화면비 옵션, 레퍼런스 상한, 프롬프트 제한: 미검증.

공개 정보로 확인한 내용:

- 2026-11-13 지멍에 Seedance 2.5 4K 등급과 480P 샘플 모드 출시 [공식 더우인 계정 / 제3자 보도].
- 가격: 언론에 나온 멤버십 환산가는 프로모션마다 바뀌어 여기 적지 않습니다 [제3자]. 결제 확인 화면이 기준.

미검증: 길이 옵션, 레퍼런스 상한, 프롬프트 제한, 반려 시 환불 여부. 대량 생성 전에 작은 테스트를 1개 돌립니다.

## 중국 내 공개: AI 콘텐츠 표시

- 「인공지능 생성·합성 콘텐츠 표시 방법(人工智能生成合成内容标识办法)」이 **2025-09-01**부터 시행: 게시자는 AI 생성임을 스스로 밝히고 플랫폼 표시 기능을 써야 하며, 표시를 악의적으로 지우거나 바꾸면 안 됩니다 [공식, `sources.md`].
- 더우인: 게시 화면에서 "添加自主声明 → 内容由AI生成"(메뉴 이름은 바뀔 수 있음).
- 표시하지 않으면 플랫폼이 "AI 생성 의심"으로 자동 표시할 수 있습니다.
- 생성 플랫폼이 넣은 AI 워터마크나 메타데이터를 지우지 않습니다.
- 이 팩은 게시나 예약을 하지 않고 완성본만 넘깁니다.

## 중국 플랫폼 작성 요령

- 중국어 드라마는 중국어로 쓰고, 대사에는 "用普通话说："와 목소리 묘사("苍老沙哑男声，带气声，中速")를 붙입니다.
- 레퍼런스는 늘 `@图片N` + 용도: "@图片3 明代白绸降书和石案（道具、字迹和冷蓝色调严格按此图）".
- 해외보다 심의가 엄격합니다: 피, 시체, 살해, 총, 불길, 구타, 미성년자 관련 민감 상황, 정치적 암시를 피합니다(`moderation-and-pitfalls.md`).
- 템플릿: `../templates/shot-prompt-domestic.md`.
