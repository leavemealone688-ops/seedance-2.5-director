# 캐릭터 고정 (얼굴 변형 막기)

## 핵심 규칙

1. **영상보다 먼저 기준 이미지를 확정합니다.** 인물마다 이미지 모델로 고정 룩 한 장(정면 미디엄, 깨끗한 배경, 고른 조명)을 만듭니다. 기준 이미지가 없으면 영상을 돌리지 않습니다.
2. **얼굴은 원본 기준 이미지에서만.** 생성된 영상의 프레임, 지난 회 영상, 포스터를 얼굴 레퍼런스로 쓰지 않습니다. 프레임에는 이미 약간의 변형이 있어서, 쓰면 회차마다 더 멀어집니다(직접 겪은 일입니다).
3. **연결 프레임은 공간만 고정합니다.** 카메라 방향, 사이즈, 동선, 조명만 가져옵니다. "Image 4의 얼굴은 가져오지 않는다"라고 쓰고, 인물이 화면에 들어올 때 "그 얼굴은 Image 4가 아니라 Image 2와 정확히 같다"라고 씁니다.
4. **업로드 순서 = 첫 등장 순서**, 번호는 작품 끝까지 고정.

## 기준 이미지 규격 (권장)

| 항목 | 권장 |
|---|---|
| 사이즈 | 정면 또는 3/4 미디엄, 머리부터 허리까지. 비율이 중요하면 전신 한 장 추가 |
| 배경 | 단색 또는 흐림, 글자·로고 없음 |
| 한 장 | 한 사람, 한 얼굴. 표정 모음 그리드는 잘라서 따로 |
| 다각도 | 몸을 많이 돌리는 인물은 옆모습·뒷모습 추가(공식 설명상 2.5는 다각도 이미지를 지원, `sources.md`) |
| 화면비 | 납품 화면비에 맞춤(세로형 드라마는 9:16 기준 이미지가 크롭 왜곡이 적음) |

## 하드 마크 (매 프롬프트에 반복)

가장 잘 틀어지는 것: 헤어 실루엣, 머리색, 안경, 장신구, 옷 색과 겹쳐 입은 구조, 특징적인 흉터·점, 멜빵 같은 액세서리.

문형: `Image 1 is the elderly woman Edna: same face, same short wavy silver-white hair, same small gold stud earrings, same teal-green linen jacket over a cream button blouse, same long navy skirt.`

- **금지 액세서리도 적습니다**: `no rings, no necklace, no glasses`.
- 물체와 붙어 버리기 쉬운 액세서리(멜빵, 체인, 가방끈): "멜빵은 그의 어깨에 또렷이 걸려 있고, 트럭·담요·개와 분리되어 있다".
- 의상 상태 변화(맨발, 걷은 소매, 흠뻑 젖음)는 이번 컷의 시작 상태에 씁니다: "그녀는 이미 맨발이다".

## 여러 인물

- 한 사람당 고정 호칭 하나 + 레퍼런스 하나 + 하드 마크 한 세트, **호칭은 끝까지 동일**.
- 대사 비트마다: "X만 말하고, Y는 입을 다물고 있다".
- 인원수 고정: "Only these two people and this one dog appear."
- 한 화면에 3명 이상: 가능하면 컷을 나누고, 꼭 같이 나와야 하면 왼쪽부터 오른쪽까지 위치를 적고 타이트한 단독 컷을 우선합니다.
- 공식 설명으로는 2.5가 여러 주체를 다룰 수 있지만, 인원이 늘수록 외모가 뒤바뀌고 대사를 남이 가져가는 일이 많아졌습니다 → 클립당 말하는 사람은 2명까지가 가장 안전합니다.

|---|---|

| TapNow | 기준 이미지를 `{{Image N}}` 칩으로. 첫 프레임은 빈 화면으로 심의를 통과시킨 뒤 인물 추가 |

## 첫 프레임

- 시작 구도가 정확해야 하면 이미지 모델로 첫 프레임을 만듭니다: **먼저 빈 플레이트로 심의를 통과하고, 그다음 인물을 넣습니다**.
- 첫 프레임은 직접 확인: 테이블에 파묻힌 사람, 손가락 개수, 소품 방향, 깨진 글자.
- 첫 프레임의 얼굴도 기준 이미지에서 가져와야 합니다.

## 얼굴이 틀어졌다면

1. 생성된 프레임을 얼굴 레퍼런스로 쓰지 않았는지? 원본 기준 이미지로 바꿉니다.
2. 하드 마크가 매 프롬프트에 있는지, 이미지와 충돌하지 않는지?
3. 인물이 들어오는 초에 "얼굴은 Image N과 정확히 같다"를 추가.
4. 화면 속 인원을 줄이거나 인물을 크게(미디엄 이상).
5. 그래도 틀어지면 다시 생성 — 후반에서 얼굴 합성은 하지 않습니다(립싱크가 깨짐).
