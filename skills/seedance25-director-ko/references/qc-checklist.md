# 생성 결과 QC 체크리스트

## 이 두 가지를 먼저

```bash
scripts/contact_sheet.sh S03_v1.mp4 S03_v1_contact.png 2 5   # 초당 2프레임 컨택트 시트
scripts/contact_sheet.sh S03_v1.mp4 S03_v1_hands.png 6 6     # 초당 약 6프레임, 손가락과 파묻힘 확인용
```
그다음 **클립 전체를 들어 봅니다**(대사, 립싱크, 음악이 들어갔는지).

## 체크리스트

**인물**
- [ ] 얼굴이 기준 이미지와 일치(인물마다, 특히 등장하는 그 초를 확인)
- [ ] 헤어 실루엣, 머리색, 의상, 액세서리, 하드 마크 일치. 금지 액세서리 없음
- [ ] 의상 상태가 맞음(맨발 / 젖음 / 코트 벗음)
- [ ] 인원수가 맞음, 지나가는 사람이 더 생기지 않음

**몸**
- [ ] 손가락 다섯 개, 붙어 버리지 않음
- [ ] 테이블 / 의자 / 차 / 동물에 파묻히지 않음, 액세서리(멜빵, 체인)가 물체에 붙지 않음
- [ ] 이동 방향이 맞음

**공간과 연결**
- [ ] 시작이 앞 연결 프레임과 일치: 카메라 쪽, 사이즈, 동선, 색
- [ ] 좌우가 바뀌지 않음, 화면 방향 유지
- [ ] 소품 위치, 개수, 상태가 맞음
- [ ] 새 문, 조명, 장치 없음. 글자가 깨지지 않음(또는 허용 범위)
- [ ] 배경 인물이 움직임

**사운드**
- [ ] 대사가 완전하고 원문 그대로, 화자가 맞음
- [ ] 립싱크 유지, 말 안 하는 인물의 입이 움직이지 않음(최종 프레임 확인)
- [ ] 이상한 소리 없음(헐떡임, 비명)
- [ ] 모델이 넣은 음악이 있나?(있으면 → 후반 음소거)

**호흡과 연기**
- [ ] 대놓고 보여 주는 제스처 없음, 렌즈 응시 없음
- [ ] 멍한 꼬리가 얼마나 되나 → 편집 아웃 점 기록
- [ ] 카메라가 의미 없는 구도에 머무르나(예: 누군가의 다리에 오래 머묾)?

**기술**
- [ ] 길이, 화면비, 해상도가 맞음(`ffprobe`)
- [ ] 있으면 안 되는 하드 컷이 있나
- [ ] 잔 질감(바위, 물, 나뭇잎, 천, 머리카락…)이 선명하고 블록 / 격자 모양 압축 노이즈가 없음

## 판정 형식

`채택 / 다듬어서 채택(아웃 점 x.x초, 음악 음소거) / 다시 생성(이유 + 바꿀 문장)`, 콘티의 컷 로그에 기록. 템플릿: `../templates/qc-report.md`.
