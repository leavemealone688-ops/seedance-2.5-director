## Vigloo Studio [팀 실측]

**노드와 기능**
- 캔버스에 Seedance 2.5 영상 노드 생성: 9:16, 720p, 길이 슬라이더 4~20초, 오디오 켬(네이티브 대사 + 현장음).
- 우클릭 메뉴: **Extend Video**(Seedance 2.5 Edit, 최소 5초, 약 300 크레딧), **Edit Video**(약 420 크레딧), **Extract frame**. **Trim은 없음** — 후반에서 처리.
- 캔버스를 새로고침하지 않습니다(저장 안 된 상태가 날아가거나 중복 제출됨).

**실사 얼굴 정책 (가장 중요)**
- 업로드 이미지나 첫·끝 프레임에 **실사 얼굴(실사풍 AI 얼굴 포함)이 있으면 반려**됩니다.
- 그래서 캐릭터는 **등록된 Character 노드**로만, 첫 프레임은 **사람 없는 빈 플레이트**로, 공간과 소품은 레퍼런스 이미지로 넣습니다.
- 프롬프트에서는 **`@이름` 칩이나 `@image1`로만 가리키고 외모를 글로 묘사하지 않습니다**(글 묘사가 캐릭터 노드와 충돌).
- `@` 앞에는 공백을 둡니다. `@` 메뉴에는 **연결된** 노드만 뜹니다.
- 목소리 고정: mp3를 `@audio1`로 붙이고 "목소리는 @audio1 기준"이라고 씁니다. 목소리만 들리고 화면에 나오면 안 되는 인물은 Character 노드를 붙이지 않고 오디오만 붙입니다.
- 보통 구성: 공간·소품 레퍼런스 1장 + Character 노드 2개(+ 선택적으로 오디오 1개).

**작성법**
- 초 단위 비트, 12~20초면 비트 4~6개.
- 방향은 부정까지 붙여 못 박습니다("반대로 뛰어간" 사고를 겪었습니다): "그녀는 복도 끝 비상문을 향해 등을 보이며 뛴다. 카메라 쪽으로 뛰지 않는다."
- 긴 클립에서는 소품이 순간이동하고 추격 동작이 생략됩니다 → 비트마다 소품 위치를 다시 적고, 추격은 짧은 비트로 쪼갭니다.
- 심의: 피 / 시체 / 살해 / 총을 쓰지 않고, 몸싸움 접촉도 없게("두 사람 사이에는 늘 간격이 있고 신체 접촉은 없다").
- 고정 마무리 문장: `只有指定角色说话，其他人不说话。原生环境音效照实生成，不要背景音乐，不要配乐，不要字幕，不要任何文字水印。`
- 템플릿: `../templates/canvas-prompt-overseas.md`, 예시: `../examples/overseas-vigloo-20s-ko.md`.

## TapNow [팀 실측]

- 캔버스 영상 노드에서 Seedance 2.5 선택, **Omni Reference** 사용, `generate_audio` 켜기.
- 480p 28초 롱테이크가 약 560 Tapies, 16:9로 납품한 적 있음(예고편).
- **이어 찍기**: 이전에 통과한 영상을 `{{Video}}` 레퍼런스로 붙이고 이어지는 프롬프트를 씁니다.
- 프롬프트 길이: 14,676자를 받은 적이 있지만, 팀 규칙은 **순수 ASCII, 2000자 이하** — 더 안정적.
- **작업 하나에 Generate는 한 번만**. 새로고침이나 더블클릭은 이중 과금됩니다.
- 이미 제출한 유료 작업은 도중에 취소하지 않습니다.

## Higgsfield

**공식 (higgsfield.ai/seedance-2.5와 API 문서, 2026-11 확인) [공식]**
- 1회 4~30초, 오디오 기본 켬(끌 수 있음).
- 레퍼런스 최대 50개: 이미지 30, 영상 10, 오디오 10.
- 화면비: 21:9, 16:9, 4:3, 1:1, 3:4, 9:16.
- API 해상도: 480p / 720p / 1080p. 웹에는 4K도 있음(공식 Threads, 2026-11-14 공지).
- Seedance 2.5 Edit(부분 수정)와 Seedance 2.5 Extend(이어 생성)도 제공.
- 공식 권장: 시작 전에 Generate 버튼에 표시된 크레딧을 확인.

**팀 기록**
- 720p · 9:16 · 5초 = 35 크레딧(초당 약 7) [팀 실측]. 1080p / 4K 가격은 미검증.
- 480p 초안 후 확정하는 Draft 모드가 있음 [제3자: 리뷰에 따르면 2026-09 출시, 미국에서는 사용 불가], 미검증.
- 2026-11 공식 모델 목록을 봤을 때 Elements(`<<<element_id>>>` 자리표시자) 지원 목록에 Seedance 2.5가 없었음 → 원본 기준 이미지를 image reference로 쓰고 Elements에 기대지 않습니다. Soul ID로 2.5를 구동할 수 있는지는 미검증.
- start_image는 카메라만이 아니라 화면 전체를 고정합니다. 첫 프레임이 완전히 같아야 할 때만 씁니다.

## API 채널 (팀 조사, 공식 가격 페이지, 2026-11)

- BytePlus / Replicate / OpenRouter / fal 등에서 Seedance 2.5를 종량제로 제공합니다. 가격은 수시로 바뀌니 쓰기 전에 공식 가격 페이지를 확인하세요.
- 파라미터 이름과 상한은 각 사 문서를 따르고, 키는 환경 변수에 두며 **절대 저장소에 커밋하지 않습니다**.

## 해외 플랫폼 작성 요령

- 영어 드라마는 영어로, 미국 드라마는 처음부터 끝까지 **American accent**.
- 캔버스 플랫폼은 칩으로 가리키는 게 먼저이고, 칩 밖의 글은 동작·카메라·사운드만 다룹니다.
- 얼굴 정책이 엄격한 곳(Vigloo)은 Character 노드 + 빈 플레이트 첫 프레임, 느슨한 곳(Higgsfield 웹)은 원본 기준 이미지를 바로 씁니다.
- 템플릿: `../templates/canvas-prompt-overseas.md`.
