# 일관성 종합 가이드

일관성은 얼굴만의 문제가 아닙니다. 컵이 다른 손에 들려 있거나, 간판 글자가 바뀌거나, 금빛 조명이 다시 파랗게 돌아가면 시청자는 이탈합니다. 아래 항목마다 **무엇을 고정할지, 어떻게 쓸지, 어떻게 확인할지**를 정리했습니다.

원칙: **일관성은 네 가지에서 나옵니다 — 에셋 바이블 + 매 프롬프트 재기술 + 연결 프레임 + QC.** 모델의 기억에 기대지 않습니다. 에셋 바이블: `../templates/asset-bible.md`.

---

## 1. 인물 (얼굴 / 헤어 / 체형 / 의상 / 액세서리 / 하드 마크)

`character-lock.md` 참고. 문형:

```
Image 1 is <label>: same face, same <hair silhouette + color>, same <build/age>, same <top>, same <bottom>, same <shoes>, same <accessories>. No <forbidden accessories>.
```
중국어:
```
@图片1 是<称呼>：脸、<发型>、<服装>、<配饰>严格按此图，不戴戒指，不戴眼镜。
```

## 2. 의상 연속성 (바뀌는 상태)

장면 타임라인을 따라 의상 상태를 추적합니다: 마른 옷 → 흠뻑 젖음, 신발 → 맨발, 코트 입음 → 벗음, 흰 셔츠 → 진흙 튐.

- 매 프롬프트를 **현재 상태**로, 현재형으로 시작: "그녀는 이미 맨발이다", "그의 셔츠는 어깨가 젖어 짙어져 있다".
- 상태 변화는 한 컷 안에서, 정해진 초에 한 번만: "3-5s: 그녀가 플랫슈즈를 벗는다".
- 이후 컷은 모두 새 상태에 "이미"를 붙이고, 에셋 바이블의 "의상 상태" 칸을 갱신합니다.
- 큰 변화(옷 전체 교체)는 접미사를 붙인 새 상태 기준 이미지: `C01-EDNA_barefoot`.

## 3. 장소 (배치 / 공간 기준점 / 세트 소품 / 간판)

**배치를 고정**: 주요 장소마다 정방향 플레이트 + 역방향 플레이트를 두고 기준점을 적습니다: 문은 어느 쪽, 창은 어느 쪽, 주요 가구, 출구 방향.

문형:
```
Same <location>: <left anchor> on the left, <right anchor> on the right, <depth anchor> at the far end, exactly as in Image 3.
楼道空间、与墙齐平的木门、右手玻璃幕墙、尽头灰色安全出口门，一律按 @图片1。
```

- **세트 소품**: 핵심만 적고("잘린 흰 케이크가 백합 바로 왼쪽에, 찻잔이 가득 찬 사람은 금발 여자뿐") 나머지는 플레이트에 맡깁니다.
- **간판과 글자**: 모델이 만든 배경 글자는 자주 깨집니다.
  - 필요 없는 글자: `the wall and door are plain and blank, no signs, no lettering of any kind`, 또는 카메라로 간판을 화면 밖으로.
  - 필요한 글자(묘비, 문자 메시지, 교지): 모델에게 생성시키되 "읽을 수 있고 일그러지지 않은 글자"라고 쓰고 올바른 글자가 있는 소품 이미지를 붙입니다. 숫자 정보(카운터, 시계)는 후반 오버레이가 더 안전합니다.
- **문 / 장치가 생겨남**: 긴 클립에서는 문에 조명, 화면, 도어스코프가 돋아납니다 → "문에는 푸시 바만 있고, 조명·화면·전자 장치는 어느 순간에도 나타나지 않는다".

## 4. 소품과 소품 상태

소품에는 **위치, 들고 있는 사람, 상태**가 있고, 비트마다 어느 것이든 바뀔 수 있습니다.

- 소품 상태표를 둡니다: `소품 | 누가 들고 있나 / 어디에 | 상태(가득/빈, 열림/닫힘, 멀쩡/깨짐) | 몇 초부터`.
- 비트마다 소품의 끝 상태를 적습니다: "End state: the bill is in her closed hand, resting in her lap."
- 건네는 순서를 고정: "이 말을 듣고 나서야 그녀는 주머니에 손을 넣는다…"
- 유일성: "처음부터 끝까지 이 종 하나뿐". 개수가 불어나기 쉬운 소품에는 반복해서 씁니다.
- 긴 클립에서 소품이 **순간이동**합니다(Vigloo 팀 실측) → 비트마다 위치를 다시 적습니다.
- 소품에도 전용 레퍼런스 이미지를: "소품은 @图片3과 똑같이 생겼다".

## 5. 조명 / 색온도 / 시간대

- 장면마다 **켈빈 값 하나 + 광원**: "서늘하고 안개 낀 아침, 약 4800K, 부드러운 흐린 날 빛". 밤 장면: "세트 안 실제 조명만".
- 조명 변화는 타임라인 안의 사건으로 쓰고 "자연스러운 변화, 초자연 효과 없음"을 붙입니다: "4초에 걸쳐 빛이 자연스럽게 3200K 금빛으로 따뜻해진다".
- 바뀐 뒤의 컷에는 "따뜻한 금빛이 끝까지 유지되고 차가운 파란빛으로 돌아가지 않는다".
- 연결 프레임이 색을 실어 나르고, 프롬프트에도 숫자를 적어 서로 확인하게 합니다.
- 시간대(새벽 / 해질녘 / 한밤)는 에셋 바이블에 적고 컷 사이에서 튀지 않게 합니다.

## 6. 이미지너리 라인 / 180도 법칙 / 화면 방향

- 장면마다 **축**(두 주인공을 잇는 선)과 **카메라가 머무는 쪽**을 정하고 기록합니다: "모든 컷은 픽업트럭 오른쪽에서".
- 매 프롬프트: "Image 4와 같은, 트럭의 같은 쪽에서 촬영".
- **화면 방향**: 인물이 왼쪽에서 오른쪽으로 걸었다면 다음 컷도 왼쪽에서 오른쪽으로. "화면 오른쪽으로 걸어간다"라고 씁니다.
- 숏/리버스숏: A는 화면 왼쪽에서 오른쪽을 보고, B는 화면 오른쪽에서 왼쪽을 봅니다. 시선을 명시: "시선은 화면 오른쪽, 분명히 그를 향한다".
- 축을 넘는 건 대본이 필요로 할 때만, 브리지 컷(중립 앵글, 인물의 움직임이 끌고 감)으로.

## 7. 날씨와 현장 분위기

- 날씨는 상태입니다: 비의 세기, 안개, 바람, 바닥의 젖은 정도 — 매 프롬프트에 다시 씁니다. "굵은 비가 돌 탁자 위로 계속 튄다."
- 현장음은 날씨를 따라갑니다: 빗소리, 바람, 먼 천둥. 비가 그치는 것도 사건으로 써야 합니다.
- 배경 인물에게는 작은 자연스러운 움직임을("배경의 조문객들이 체중을 옮기고 고개를 살짝 돌리며 제자리에 있다") 주지 않으면 굳어 버립니다.

## 8. 회차 간 일관성

- 시리즈 전체에 **캐릭터 바이블** 하나: 기준 이미지, 하드 마크 문구, 목소리 묘사, 금지 액세서리. 하드 마크 문구는 매 프롬프트에 그대로 붙여 넣습니다.
- 같은 정방향·역방향 플레이트를 재사용하고, 리모델링이나 계절 변화는 접미사를 붙인 새 버전으로.
- 목소리: 매 회 같은 목소리 묘사, 해외 캔버스에서는 같은 `@audio1`.
- "지난 이야기" 컷도 지난 회 프레임을 얼굴 레퍼런스로 쓰지 않습니다.

## 9. 에셋 라이브러리와 이름 규칙

```
assets/
  characters/  C01-EDNA_front.png  C01-EDNA_side.png  C01-EDNA_barefoot.png
  scenes/      S01-CLINIC_main.png  S01-CLINIC_reverse.png
  props/       P01-BELL.png  P02-LETTER_blank.png  P02-LETTER_signed.png
  audio/       V01-COLE_voice_3s.mp3
episodes/EP01/
  shots/  S03_v1_prompt.txt  S03_v1.mp4  S03_v1_contact.png  S03_v1_cut.png
```

- 확정된 ID는 다시 쓰지 않습니다. 상태 변형은 접미사를 붙이고 원본은 그대로 둡니다.
- 프롬프트마다 레퍼런스 순서를 콘티에 기록: 예) `1=C01-EDNA_front / 2=C02-COLE_front / 3=A01-DOG / 4=EP01_S02_v2_cut`.
- 컷 버전은 `_v1 _v2`, 채택본은 콘티에 "확정"으로 표시.

## 10. 일관성 QC (생성할 때마다)

- 얼굴, 헤어, 의상, 액세서리를 기준 이미지와 항목별로 대조(컨택트 시트).
- 소품 위치, 개수, 상태가 소품표와 일치.
- 색이 이전 연결 프레임과 일치 — 튀지 않음.
- 카메라가 같은 쪽, 좌우가 바뀌지 않음, 화면 방향 유지.
- 새 문, 조명, 장치 없음, 깨진 글자 없음.
- `qc-checklist.md` 참고.
