# 화면비, 해상도, 공모전 규격, 예산

## 9:16 vs 16:9

| | 9:16 세로 | 16:9 가로 |
|---|---|---|
| 용도 | 세로형 숏드라마, 더우인, Shorts, Reels | 공모전, 예고편, 롱폼 플랫폼 |
| 구도 | 인물이 화면을 더 많이 채움. 미디엄 클로즈업 단독 위주, 투샷은 위아래로 엇갈리거나 전경/후경으로 | 가로 동선, 대칭 투샷, 오버더숄더, 와이드 설정 숏 |
| 쓰는 법 | 첫 문장에 `Vertical 9:16`, 피사체는 중앙에, 위아래 UI와 겹치지 않게 | `16:9 cinematic widescreen`, 2.35:1 시네마스코프 느낌도 요청 가능 |
| 위험 | 가로 동작이 화면 밖으로 나감, 답답함 | 세로 플랫폼에서 잘림 |

- 기준 이미지와 연결 프레임은 가능하면 납품 화면비에 맞춥니다.
- **크롭으로 변환하지 않습니다**: 둘 다 필요하면 둘 다 생성하거나, 안전 영역(피사체 중앙, 여백)을 두고 크롭합니다.
- 공모전 규격(길이, 해상도, 프레임레이트, 자막 규정, AI 표시 허용 여부): 먼저 요강을 읽고 프로젝트 계획 첫 줄에 적습니다. 이 팩은 어떤 공모전에 대해서도 판단하지 않습니다.

## 해상도

- 우리는 보통 720P / 720p로 납품합니다. 구도와 연기는 낮은 해상도(480p 초안)로 먼저 테스트하고, 만족스러우면 고해상도로 — 예산을 아낍니다.
- 1080p / 4K: 지멍과 Higgsfield가 4K 등급을 공식 출시 [공식, 2026-11], 가격은 미검증.
- 프레임레이트: Vigloo 프롬프트에 24fps라고 쓴 적은 있지만, 실제 출력 프레임레이트는 플랫폼이 정합니다 — `ffprobe`로 확인.

## 예산

제출 전에 계산하고 담당자의 승인을 받습니다:

```bash
python3 scripts/cost_calc.py --platform xiaoyunque --clips 8 --retry 0.5
python3 scripts/cost_calc.py --platform vigloo --seconds 20 --clips 4 --retry 0.5
```

- 단가표는 `scripts/cost_calc.py` 맨 위에 출처와 날짜와 함께 있고, 검증되지 않은 조합은 스크립트가 거부합니다.
- 대사 컷은 보통 1~2버전이 필요 → 기본 재시도 여유 50%.
- 추정 ≠ 실제 차감. 결제 확인 화면 / Generate 버튼이 기준이고, 제출 후 실제 차감을 기록합니다.
- 절약: 초안 등급으로 실험, 한 번에 작업 하나, 편집으로 고칠 수 있는 건 다시 생성하지 않기, CLI 제출은 웹 할인이 안 될 수 있음(LibTV, 실측).

| 플랫폼 | 참고 가격 (2026-11 기준, 확인 필요) | 출처 |
|---|---|---|
| 샤오윈췌 | 10초 클립 1개당 200 크레딧(9:16, 720P, 参考生成) | 팀 실측 |
| LibTV | 9초 = 348 크레딧(84% 할인 포함, 웹), CLI는 정가 | 팀 실측 |
| Vigloo Studio | 초당 약 29 크레딧(12초 = 350, 20초 = 580), Extend 약 300, Edit 약 420 | 팀 실측 |
| TapNow | 480p 28초 ≈ 560 Tapies | 팀 실측 |
| Higgsfield | 720p 5초 = 35 크레딧 | 팀 실측 |
| 지멍 | 미검증 | — |

크레딧과 현금의 환산은 멤버십 등급에 따라 다르므로 이 팩에서는 환산하지 않습니다.
