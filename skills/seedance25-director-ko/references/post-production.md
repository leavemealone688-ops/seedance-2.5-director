# 후반 작업

## 1. 죽은 꼬리 자르기

- 모델은 끝에 몇 초씩 멍하니 바라보거나 의미 없는 구도에 카메라를 세워 두곤 합니다. QC에서 아웃 점을 기록하고 자릅니다.
- 아웃 점은 다음 컷의 연결 프레임 시점이기도 합니다(`scripts/cut_frame.sh`).
- 앞쪽 0.5~1초의 "예열"도 잘라서 첫 프레임부터 동작이 있게 할 수 있습니다.

## 2. 모델이 넣은 음악 없애기

"음악 없음"이라고 써도 모델이 피아노를 넣을 수 있습니다. 순서대로:
1. 음악이 대사와 섞여 있으면 보컬 분리 도구로 목소리 + 현장음만 남깁니다(결과는 들쭉날쭉, 끝나고 들어 보기).
2. 대사가 없는 클립은 그냥 음소거하고 후반에서 현장음을 다시 깝니다.
3. 회차 전체의 음악은(필요하면) 후반에서 깔아 음악이 끊기지 않게 합니다.

```bash
# 영상만 남기고 오디오 전부 제거
ffmpeg -i in.mp4 -c:v copy -an out_silent.mp4
# 프레임 정확도로 자르기(재인코딩)
ffmpeg -i in.mp4 -ss 0 -to 6.0 -c:v libx264 -crf 18 -c:a aac out_trim.mp4
```

## 3. 라우드니스

- 회차 전체를 정규화합니다(숏폼 플랫폼은 흔히 -14 LUFS 안팎을 목표로 함, 플랫폼 규격을 따를 것):
  `ffmpeg -i in.mp4 -af loudnorm=I=-14:TP=-1.5:LRA=11 -c:v copy out.mp4`

## 4. 하드 자막

- **자막에 문장부호를 쓰지 않습니다**: 줄 중간은 띄어쓰기로 끊고 끝에 마침표를 찍지 않습니다. 물음표와 느낌표도 빼고 줄바꿈으로 어조를 전합니다.
- 큰 글씨, 높은 대비, 외곽선이나 박스. 세로 영상은 아래 3분의 1보다 위에, 플랫폼 오른쪽 버튼과 하단 캡션 영역을 피해서.
- 한 줄에 중국어 12~16자 또는 라틴 문자 32~40자 정도(경험칙). 한국어는 미검증이지만 대략 14~18자부터 시작해 보세요.
- 외국어 드라마는 콘티의 번역 칸을 기준으로 자막 타이밍을 잡습니다.
- 프롬프트에는 늘 "자막 없음", 자막은 후반에서만 넣습니다.

## 5. 썸네일

- **세로 9:16**(YouTube Shorts, 더우인, Reels 모두 세로 썸네일). 가로 영상은 16:9를 따로 만듭니다.
- 가장 강한 프레임(표정이 가장 크고 갈등이 가장 분명한)을 쓰거나, 기준 이미지로 이미지 모델에서 선명한 버전을 다시 만듭니다.
- 갈등이나 서스펜스를 담은 큰 글자 3~8자(단어), 스포일러 없이. 글자는 중앙 위쪽, 플랫폼 UI를 피해서.
- 썸네일 속 인물은 기준 이미지와 일치해야 합니다.
- 자세한 건 `viral-hooks.md` → "썸네일과 제목".

## 6. 세로 ↔ 가로

- 9:16을 16:9로 크롭하면 머리와 발이 잘립니다. 둘 다 필요하면 **둘 다 생성**하거나, 안전 영역(피사체 중앙, 위아래 여백)을 두고 생성해서 크롭합니다.
- 공모전이 16:9를 요구하면 콘티 단계부터 16:9 구도로 설계합니다(`formats-and-budget.md`).

## 7. 납품 목록

- 최종본(최고 해상도) + 작은 미리보기
- 썸네일(화면비 일치)
- 자막 파일(SRT, 플랫폼 캡션이나 번역용)
- 컷 목록과 레퍼런스 목록(재사용용)
