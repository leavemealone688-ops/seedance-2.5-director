# 대본 → 콘티 → 생성 단위

## 1. 대본 층 (촬영 가능한 대본)

장면마다:
- 씬 번호, 장소, 시간(빛), 등장인물
- **이 장면이 하는 일**(무엇을 진전시키고 무엇을 회수하나)
- 지문(카메라가 볼 수 있는 것만)
- 대사(원문, 화자와 목소리 포함)

규칙:
- 보이거나 들리는 것만 — 속마음은 쓰지 않고 동작이나 대사로 표현합니다.
- 장면마다 한 가지를 진전.
- 앞에는 훅, 끝에는 질문(`viral-hooks.md`).
- 모든 소품과 동작에는 이유가 있고 뒤에서 쓰입니다.
- 템플릿: `../templates/episode-script.md`.

## 2. 콘티 층

대본을 컷으로 나눕니다: 사이즈, 카메라(축의 어느 쪽), 무빙 하나, 동작, 대사, 사운드, 어느 프레임에서 시작하는지, 끝 상태.

- 템플릿: `../templates/storyboard-table.md`.
- 각 컷의 시작은 앞 컷의 끝과 맞아야 합니다(`continuity.md`).
- 컷마다 보상이 터지는 초를 표시.

## 3. 생성 단위 층

프롬프트 하나 = 생성 단위 하나:
- 10초 단위: 1컷, 또는 2컷(3~4초 + 6~7초).
- 9~15초: 2~4컷.
- 15~30초: 긴 클립, `long-takes.md` 참고.

합치는 기준: 시간과 공간이 이어지고, 같은 인물들이고, 동작이 단순하면 하나로. 군중, 복잡한 액션, 장소 전환은 나눕니다.

템플릿: `../templates/script-to-shots.md`.

## 4. 프롬프트를 넘기기 전에

- [ ] 비트표(초 / 사이즈 / 동작 / 대사 / 사운드)
- [ ] 레퍼런스 업로드 순서
- [ ] 글자 수 ≤ 플랫폼 제한(`scripts/count_chars.sh`)
- [ ] still / as before / 이전 버전 언급 없음
- [ ] 일부러 보여 주는 상징적 제스처 없음
- [ ] "음악 없음 / 자막 없음"을 두 번 씀
- [ ] 예산 계산 완료, 승인 대기

## 5. 복잡한 동선

인원이 많거나 움직임이 복잡하거나 카메라가 정밀해야 하는 장면: 화이트박스 / 3D 프리비즈로 동선을 잡아 카메라 레퍼런스로 붙인 다음 프롬프트를 씁니다.
