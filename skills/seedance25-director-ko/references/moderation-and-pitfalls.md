# 심의와 자주 겪는 함정

## 심의에 안전한 표현

| 유형 | 권장 |
|---|---|
| 피, 상처, 의료 행위 | `no blood, no medical procedure`. 상처는 "깨끗한 붕대"로, 화면에 수술 없음 |
| 무기 | 가능하면 "no weapons", 꼭 필요하면 실루엣이나 번쩍임만 |
| 불, 폭발 | 빛의 색으로 암시, "no open flame". 판타지의 불은 "검붉은 주황빛"으로, 사람을 태우지 않음 |
| 격투 | 구타나 짓밟는 클로즈업 없음. "손목을 누른다" 같은 절제된 동작, "두 사람 사이에는 늘 간격이 있고 신체 접촉은 없다", 발과 부츠는 화면 밖 |
| 민감어 | 중국어에서는 血 / 尸体 / 杀 / 枪 / 死를 피하고 "쓰러진다", "움직이지 않는다", "붉은 액체도 없다"로 |
| 실존 인물, 브랜드, 로고 | 실명 금지. 차, 옷, 간판: "no logos, no lettering" |
| 미성년자 | 민감한 상황은 모두 피함 |
| 역사 / 정치 | 허구화, 실제 정치 암시 없음 |
| 노출 | 옷을 완전히 갖춰 입은 상태로 묘사 |
| 실사 얼굴 레퍼런스(해외 캔버스) | Vigloo는 실사 얼굴이 있는 업로드를 반려 → Character 노드 + 빈 플레이트 첫 프레임 |

안전 문구:
- `No weapons, no blood, no fire, no medical procedure. No text on screen.`
- `不出现武器、血迹、明火。画面中不要任何文字、字幕、水印。`

## 반려된 뒤에

1. 샤오윈췌 "视频可能不合规": **그대로 재제출**(우리 경험: 환불되고, 통과하는 경우가 많음).
2. 그래도 반려되면: 가장 의심되는 민감어를 절제된 표현으로 바꾸고, 바꾼 내용을 기록하고, 먼저 담당자에게 알립니다.
3. 레퍼런스 이미지도 원인이 될 수 있습니다(상처나 무기 소품 이미지). 필요하면 교체.

## 화질 함정 (팀 실측)

| 함정 | 원인 / 증상 | 해결 |
|---|---|---|
| 얼굴 변형 | 생성된 프레임을 얼굴 레퍼런스로 씀 | 원본 기준 이미지만 |
| 사람이 테이블 / 의자에 파묻힘 | 여러 명이 앉아 있고 상체가 테이블 가장자리와 합쳐짐 | "solid, physically correct contact", 첫 프레임 확인, 인원 줄이기 |
| 손가락 개수 오류 | 복잡한 손동작, 클로즈업 | "natural hands with five fingers", 손은 미디엄 사이즈에서 단순한 주먹/손목 잡기, 약 6fps로 손가락 세기 |
| 격자 / 블록 노이즈 | 잔 질감: 자갈, 풀, 카펫 | 화면에 실제로 있는 잔 질감을 짚고 "sharp fine detail, no blocky or grid-like compression artifacts"를 요구(`universal-rules.md` §9). 화면 속 잔 질감 비중 줄이기, 사이즈 조금 타이트하게. 약하면 수용, 심하면 다시 생성 |
| 배경 인물이 굳음 | 배경 동작을 쓰지 않음 | 작은 자연스러운 움직임 + "제자리에 있다" |
| 간판 글자 깨짐 | 모델이 지어낸 글자 | "plain, blank, no lettering", 카메라를 돌림 |
| 소품 순간이동 / 증식 | 특히 긴 클립 | 비트마다 위치와 "이것 하나뿐"을 다시 씀 |
| 추격 동작 생략 | 긴 클립에 동작이 너무 많음 | 짧은 비트로 나누고 비트마다 동작 하나 |
| 반대 방향으로 뜀 | 방향이 모호함 | 방향 고정 + 부정 추가 |
| 컷이 더 생김 | SHOT/CUT 라벨 또는 비트 과밀 | 라벨 삭제, 내용 줄이기 |
| 말 안 하는 인물이 입을 움직임 | 조용히 있으라고 하지 않음 | `mouth stays closed, no lip movement`, 최종 프레임 QC |
| 피아노 / 스코어가 들어감 | 모델 습관 | "음악 없음" 두 번 + 후반 음소거 |
| 멍한 꼬리 | 마지막 비트가 너무 비어 있음 | 마지막 비트는 1초만, 후반에서 자름 |
| 대놓고 보여 주는 제스처 | 프롬프트가 의식 같은 동작을 요구 | 지우기, `acting-and-pacing.md` 참고 |
| "얼굴이 끝까지 안 나오는 인물"이 깨짐 | 비트마다 다시 써야 함 | 비트마다 "카메라에 등을 보인다 / 얼굴은 화면 밖" 다시 쓰기 |

## 작업 규율

- 작업 하나에 생성 클릭 한 번. 캔버스 새로고침이나 더블클릭 금지(TapNow / Vigloo는 두 번 과금).
- **유료 작업을 생성 도중에 취소하지 않습니다.**
- 한 번에 작업 하나. 앞 작업이 통과한 뒤 다음을 돌리고, 같은 작업을 동시에 중복 제출하지 않습니다.
- 제출할 때마다 "플랫폼, 설정, 레퍼런스 순서, 예상 비용"을 담당자에게 정리해 보여 주고 승인을 기다립니다.
