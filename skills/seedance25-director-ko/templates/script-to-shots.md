# 템플릿: 대본 → 컷 → 생성 단위

## 1단계: 장면 하나

```
씬 03　동물병원 입구　서늘한 아침 안개 → 따뜻해짐　등장: 에드나, 콜, 보(개)
목적: 에드나가 한마디로 콜의 두려움을 내려놓게 한다(회수: 콜이 고개를 든다)
지문: 에드나가 현관에서 픽업트럭으로 걸어와 콜 옆에 선다.
대사: 에드나(따뜻하고 약간 허스키한 노년 여성 목소리): "Don't let fear be what he sees. Let him see his partner."
반응: 콜이 그녀를 올려다보고, 숨을 한 번 쉬고, 보를 내려다본다.
```

## 2단계: 컷으로 나누기

| 컷 | 사이즈 / 카메라 | 내용 | 시작 지점 |
|---|---|---|---|
| 3A | 미디엄 / 트럭 오른쪽 | 에드나 등장, 멈춤 | 앞 장면 끝, 테일게이트 위의 콜 |
| 3B | 미디엄 클로즈업 / 같은 쪽 | 에드나의 대사 | 3A 끝 |
| 3C | 미디엄 / 같은 쪽 | 콜의 반응 | 3B 끝 |

## 3단계: 생성 단위로 합치기

같은 시공간, 같은 인물, 단순한 동작 → 3A+3B+3C를 **U03(10초 원테이크)**으로:

| 초 | 내용 |
|---|---|
| 0-2s | 앞 컷의 사이즈로 시작. 에드나가 현관 쪽에서 들어와 콜 옆에 멈춘다 |
| 2-7s | 에드나가 콜을 보며 대사. 에드나만 말한다 |
| 7-10s | 콜이 고개를 들고, 숨 한 번, 보를 내려다본다. 오래 바라보는 홀드 없음 |

## 4단계: 프롬프트 쓰기

`shot-prompt-domestic.md` 또는 `canvas-prompt-overseas.md`를 씁니다.

## 5단계: 셀프 체크

- 비트마다 주요 사건이 하나뿐인가?
- 시작이 앞 컷의 끝과 맞는가?
- 대놓고 보여 주는 상징적 제스처가 있나?
- 보상은 몇 초에? 회차 끝에 질문이 남는가?
