# 예시 프롬프트

우리 팀이 실제로 Seedance 2.5에 제출한 프롬프트를 다듬은 것입니다("미생성", "뼈대"로 표시한 두 개를 빼면 모두 생성까지 마침). 인물·프로젝트 이름은 가상의 이름으로 바꿨고, 계정·경로·프로젝트 정보는 지웠으며, 이전 버전을 가리키는 "still / as before" 표현은 이 팩의 규칙에 따라 현재형으로 고쳤습니다. 중국어·한국어 프롬프트 본문은 플랫폼이 실제로 받은 원문 그대로 두고, 설명만 번역했습니다.
