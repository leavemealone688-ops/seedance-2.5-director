# Example prompts

Adapted from prompts our team actually submitted to Seedance 2.5 (all rendered, except the two marked "not rendered" and "skeleton"). Character and project names are fictional replacements; accounts, paths and project details are removed; "still / as before" references to older versions were rewritten in the present tense per this pack's rules. Chinese and Korean prompt bodies are kept in the original language, since that is what the platform received; notes are translated.

| File | Platform / settings | What it shows |
|---|---|---|
| `domestic-10s-dialogue-continuity-en.md` | Xiaoyunque · 参考生成 · 9:16 · 10s · 720P | Dialogue shot; continuity frame controls only camera and blocking; stops the previous shot's character from shrinking into the background; 0-2/2-7/7-10s; version after removing on-the-nose gestures |
| `domestic-10s-silent-light-en.md` | Same | No dialogue; a natural small action (slipping off shoes without looking down or using hands); 4800K→3200K natural shift; camera move hides signage; trimmed under 5000 characters |
| `domestic-10s-kneel-dialogue-en.md` | Same | Face on entry "matches the portrait, not the continuity frame"; practical action instead of a ceremonial kneel; one breath at the end |
| `domestic-4s-closeup-zh.md` | Xiaoyunque · 16:9 · 4s | Chinese `@图片N` syntax; hand close-up with only a simple wrist grip; cool blue continuity; single camera move |
| `domestic-10s-two-shot-zh-16x9.md` | Xiaoyunque · 参考生成 · 16:9 · 10s · 720P | Two shots in one clip (3.5s+6.5s); Mandarin lines + voice; "kneeling from frame one" locks the pose; boots out of frame to stay moderation-safe |
| `overseas-vigloo-20s-ko.md` | Vigloo Studio · 9:16 · 720p · 20s | `@Character` chips + `@image` + `@audio1`; native Korean dialogue; voice through a door; locked direction; fixed closing line |
| `longtake-30s-skeleton.md` | Generic (TapNow / Higgsfield / 30 s tier) | One-take + end-state anchors + push-in written as a physical process (structural skeleton, not a rendered prompt) |

Usage: copy the closest one and swap characters, location and timeline using `../templates/`.
