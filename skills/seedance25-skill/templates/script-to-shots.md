# 模板：剧本 → 镜头 → 生成单元

## 第 1 步：一场戏

```
场 03　诊所门口　清晨冷雾 → 转暖　在场：Edna、Cole、Bo（狗）
作用：Edna 用一句话让 Cole 放下恐惧（兑现：Cole 抬眼）
动作：Edna 从门廊走到皮卡旁，站到 Cole 身边。
对白：Edna（温暖略沙哑的老年女声）："Don't let fear be what he sees. Let him see his partner."
反应：Cole 抬眼看她，吸一口气，低头看 Bo。
```

## 第 2 步：拆镜头

| 镜头 | 景别 / 机位 | 内容 | 开场接 |
|---|---|---|---|
| 3A | 中景 / 车右侧 | Edna 入画，站定 | 上一场结尾 Cole 在尾门 |
| 3B | 中近景 / 同侧 | Edna 说台词 | 3A 结尾 |
| 3C | 中景 / 同侧 | Cole 反应 | 3B 结尾 |

## 第 3 步：合并成生成单元

同一时空、同一组人、动作简单 → 3A+3B+3C 合成 **U03（10 秒一镜到底）**：

| 秒段 | 内容 |
|---|---|
| 0-2s | 开场同上一镜构图；Edna 从门廊一侧入画，停在 Cole 身边 |
| 2-7s | Edna 看着 Cole 说台词；只有 Edna 说话 |
| 7-10s | Cole 抬眼，一口气，低头看 Bo；不留长对视 |

## 第 4 步：写提示词

套 `shot-prompt-domestic.md` 或 `canvas-prompt-overseas.md`。

## 第 5 步：自检

- 每秒段只有一件主要的事？
- 开场与上一镜结尾对得上？
- 有没有刻意象征动作？
- 兑现点在第几秒？集尾有没有问题留下？
