# 后期

## 1. 剪死尾巴

- 模型常在结尾留几秒空看、或镜头停在无意义构图上。QC 时记下出点，剪掉。
- 出点同时就是下一镜的衔接帧时间（`scripts/cut_frame.sh`）。
- 开头如果有 0.5-1 秒的"起势"也可以剪，让第一帧就有动作。

## 2. 静音模型配乐

即使写了 no music，模型仍可能加钢琴。处理顺序：
1. 单条片段里音乐和对白混在一起时，用人声分离工具把人声 + 环境声留下（效果因片而异，处理后回听）。
2. 无对白片段可以直接静音，后期另铺环境声。
3. 整集统一后期配乐（如需要），保证音乐连贯。

```bash
# 只要画面、去掉全部音轨
ffmpeg -i in.mp4 -c:v copy -an out_silent.mp4
# 裁剪（重新编码，帧精确）
ffmpeg -i in.mp4 -ss 0 -to 6.0 -c:v libx264 -crf 18 -c:a aac out_trim.mp4
```

## 3. 响度

- 全集统一响度（短视频平台常见目标约 -14 LUFS 左右，以平台规范为准）：
  `ffmpeg -i in.mp4 -af loudnorm=I=-14:TP=-1.5:LRA=11 -c:v copy out.mp4`

## 4. 烧录字幕

- **字幕不加标点**：句中用空格断开，句末不加句号。问号、感叹号也去掉，语气靠断行。
- 大字号、高对比、描边或底框；竖屏放在画面下 1/3 以上，避开平台右侧按钮和底部文案区。
- 一行不超过约 12-16 个汉字或 32-40 个英文字符（经验值）。
- 外语剧出中文或英文字幕时，按分镜表里的翻译对时间轴。
- 提示词里永远写"不要字幕"，字幕只在后期加。

## 5. 封面

- **竖屏 9:16**（YouTube Shorts、抖音、Reels 都用竖版封面）；横屏片另做 16:9。
- 用成片里最强的一帧（表情最大、冲突最清楚的瞬间），或用图片模型按定妆照重做高清版。
- 封面大字 3-8 个字，写冲突或悬念，不剧透结局；字放在中上部，避开平台 UI。
- 封面人物也必须和定妆照一致。
- 更多见 `viral-hooks.md` 的"封面与标题"。

## 6. 横竖转换

- 9:16 → 16:9 直接裁会丢头脚；需要两种画幅时**分别生成**，或生成时保留安全区（主体居中，上下留空）。
- 参赛片要求 16:9 时，从分镜阶段就按 16:9 设计构图（见 `formats-and-budget.md`）。

## 7. 交付清单

- 成片（最高分辨率）+ 小体积预览版
- 封面（对应画幅）
- 字幕文件（SRT，供平台自动字幕或翻译）
- 镜头清单与参考图清单（便于复用）
