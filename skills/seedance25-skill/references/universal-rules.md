# 通用写法规则（所有平台）

> 依据：团队在小云雀、LibTV、TapNow、Vigloo Studio 的实际生产经验，加上公开的官方指南（火山方舟《Seedance 2.5 提示词指南》、小云雀官方手册、BytePlus 英文版），见 `sources.md`。官方与实测冲突时，以你所在平台的实测为准。

## 1. 提示词骨架（四段，顺序别乱）

```
① 素材指代：每张参考图 / 视频 / 音频是谁、用来锁什么、不锁什么
② 一句话总述：画幅 + 时长 + 类型质感 + 地点 + 事件 + 镜头形态（一镜到底 / N 个镜头）
③ 逐秒时间线：0-2s … / 2-7s … / 7-10s …（每段：景别机位 + 动作 + 台词 + 声音 + 结束状态）
④ 贯穿项与禁止项：全程保持的光色、人数、服装状态；不要字幕 / 不要背景音乐 / 不要水印
```

参考图已经准确时，**只做指代，不要把图里的东西再长篇复述**，复述会和图打架、稀释时间线的注意力。只有图里看不清、或必须防漂的硬记号（发型轮廓、耳钉、袖口颜色）才重复写。

## 2. 逐秒时间线

- **整数秒**，首尾相接，最后终点 = 总时长。不写 `6.7s`，不留 `0-3s … 5-6s` 这种空档（空档会让模型自由发挥）。
- **每段只变一件主要的事**。内容太少，模型乱加；内容太多，会被多切几刀或漏剧情。
- 每段末尾可加一句**结束时可见状态**（`End state: the cup stays on the saucer`），这是最便宜的稳定锚。
- 不要用时间戳控制高频动作（"一秒摇头三下"）。
- 10 秒单条常见节拍：`0-2s 进入/建立 → 2-7s 主事件（台词）→ 7-10s 反应/落点`。
- 9-15 秒可放 2-4 个镜头；12-20 秒写 4-6 个节拍；20-30 秒见 `long-takes.md`。

## 3. 一镜到底 vs 多镜头

- **一镜到底**：写 `One continuous shot` / `一镜到底`，运镜写成"同一物理空间里的连续移动"（"摄影机沿轨道向前滑近约 40 厘米，画框边缘连续内收"）。**不要**写 `SHOT 1`、`CUT`、全大写 `CAMERA PUSH` 这种标签，它们会诱发硬切。
- **多镜头**：用 `镜头1（0-3秒·中景·固定）` 或 `【镜头N（a-b 秒·景别·唯一运镜）】`，写明 `硬切`。每个镜头 ≥ 3 秒，一个镜头最多一句主要台词。
- **一段只用一个主运镜**。推、摇、跟不要叠在同一拍。

## 4. 只描述当前画面

模型只看得到这一条提示词和这几张图，看不到你之前的版本和别的镜头：

| 不要写 | 改成 |
|---|---|
| Cole still sits on the tailgate | Cole sits on the left edge of the open tailgate |
| as before / same as last shot | 直接写出机位、站位、光色 |
| 修改后的门不再有灯 | 门上只有一根横推杆，没有任何灯和设备 |
| 回到上一段的位置 | 写清具体位置："站在皮卡右侧，离镜头约两米" |
| 她又一次摇铃 | 只写这一条里发生的次数："她摇两下铃" |

## 5. 负面约束

- 团队规则：负面写成 **FORBIDDEN / 禁止 / 不要**，不写 avoid（avoid 太软）。
- 官方与社区实测：视觉上写"不要特写 / 不要切镜"有时反而把概念唤进画面。所以：
  - **声音与叠加层**（字幕、BGM、配乐、水印）→ 直接写负面，开头结尾各一次，穷举同义词：`no music, no piano, no score, no BGM`。
  - **视觉内容** → 优先写成全程可见的正向状态："门框、整张桌和四个人始终在画面里"、"画面下缘只到膝盖以上"。
  - 必须禁止的视觉项集中到最后一段，短句，不超过 6-8 条。
- 固定结尾句（Vigloo 团队写法，国内也通用）：`只有指定角色说话，其他人不说话。原生环境音效照实生成，不要背景音乐，不要配乐，不要字幕，不要任何文字水印。`

## 6. 人物与参考绑定

- 开头给每个人一个固定称呼并绑定参考：`Image 1 is the elderly woman Edna` / `@图片1 监军`。全文用同一称呼，不要一会儿"她"、一会儿"老太太"。
- 按**首次出场顺序**上传参考图，提示词编号与上传顺序一一对应。
- 衔接帧永远放最后一张，并写"只取机位、景别、站位、光色，不取脸、文字、标识"。
- 写明人数："Only these two people and this one dog appear."

## 7. 方向与空间

- 方向要写死，必要时加否定："她朝画面右侧的安全门跑，不是朝镜头跑"。
- 写清人物左右："Cole sits on the left edge of the tailgate; Edna stands at his right."
- 门、楼梯、车头朝向写清楚："左舵车"、"门保持竖直、关着"。

## 8. 写法细节

- 中文平台用中文或英文都可以；团队在小云雀英文剧全程用英文，中文剧用中文。同一条不要中英混写说明句（台词除外）。
- 海外画布团队规则：**纯 ASCII、≤ 2000 字符**更稳（TapNow 实际接受过 14,676 字符，但长不等于好）。
- 每条交付前用 `scripts/count_chars.sh` 数字符，超限只删重复说法，不删内容。
- 小众术语要配可见解释：`ease-in` → "起步很慢、逐渐加速"。
- 不写品牌、真人名字、真实地名招牌。

## 9. 复杂调度先预演

人多、走位复杂、运镜要精确时：先用白模 / 3D 预演 / 智能预演定机位和走位，再挂预演视频写"@视频1 只参考运镜和机位轨迹，不参考外观、材质和场景"。官方说明 2.5 加强了白模参考能力（见 `sources.md`）。
